# /end-chat-force — срочное закрытие: спаси то, что нельзя потерять, и уходи

Человеку нужно закрыть этот чат СЕЙЧАС. Скорость важнее церемоний — но никогда не важнее
эстафеты: закрытие, теряющее главное, не быстрое, а разрушительное. Три шага, минуты в сумме.

## Шаг 1. Эстафета — только то, что нельзя потерять

Обнови `STATUS.md`, сжато:

- **Что сделано в этом чате** — факты, которые чужой не восстановит из одного git.
- **Где мы** — что работает, что в полёте и в каком состоянии.
- **Что следующая сессия делает ПЕРВЫМ** — команды, пути, открытые вопросы и чьи они.
- **Строка долга церемоний** — добавь дословно:
  `⚠️ Форс-закрытие <дата+время>: церемонии пропущены (проход судьи, стрижка бонсая, README,
  линтеры витрины) — первый /end-chat-soft платит этот долг.`
- Переводи относительные даты в абсолютные.

Незакоммиченная работа, которую нельзя безопасно приземлить: НАЗОВИ её в эстафете (файл,
состояние, следующий ход) вместо доделывания — названное выживает, спешка портит.

## Шаг 2. Закоммитить и запушить

Коммить через гейт проекта и пушь:

```bash
npm run kaif:check && git add -A && git commit -m "..." && git push
```

⚠️ **`npm run kaif:check` обязателен и в форс-режиме** — он падает, если в git попал секрет или
ПДн (здесь это уже случалось однажды; см. `AGENT_GUIDE.md` → «Гейт перед push»). Трейлер
соавторства — канон `AGENT_GUIDE.md` → «Коммиты».

Если сборка заведомо сломана — скажи это В сообщении коммита (префикс `wip:`): честное сломанное
состояние лучше молча потерянного. Push отклонён (non-fast-forward) — `git pull --rebase`,
повтори один раз; не вышло — скажи человеку: коммит существует локально, ничего не потеряно.

## Шаг 3. Прощание одной строкой

Одна строка человеку: хеш коммита, самое важное для следующего чата и напоминание, что долг
церемоний записан в `STATUS.md` — с префиксом-строкой доставки
`DELIVERY: <метрика владельца> X → Y; moved by: … | blocker: …` (метрика — из `MASTER_PLAN.md`;
срочный режим пропускает церемонии, но никогда — учёт). Прощай.

## Что этот скилл отказывается пропускать

- **Эстафету.** Никакого закрытия без шага 1 — это то единственное, ради защиты чего форс-режим
  существует.
- **Гейт перед push.** Размашистый `git add`, прихвативший случайные файлы владельца, — не
  быстрее, а утечка; отказ гейта уважается и в форс-режиме.
- **Честность.** Пропущенные церемонии ОБЪЯВЛЯЮТСЯ (строка долга), а не выбрасываются молча —
  форс-закрытие, притворяющееся полным, и есть фрод, за которым охотится `/fable-judge`.

## Заметки

- Семейство в одну строку: **/pause — чат продолжится позже; /end-chat-soft — доделай как
  следует, потом попрощайся; /end-chat-force — зафиксируй главное и попрощайся прямо сейчас.**
- Форс-режим — выбор человека, а не срезание угла агентом: никогда не выбирай его по своей
  инициативе только потому, что сессия затянулась.
