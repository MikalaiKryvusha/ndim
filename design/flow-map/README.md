## 1. Что это такое одной фразой

**Лист, на котором виден весь продукт как он есть сегодня** — живые экраны, живые компоненты, живые
токены — с панорамой, зумом, трубопроводом переходов и страницами, как в Фигме. Открывается двойным
щелчком, без служб и без интернета.

## 2. Чем это НЕ Фигма — и почему это преимущество, а не бедность

Разведка `researches/66` (за что дизайнеров тянет к Фигме и что их в ней бесит) даёт главную
развилку. В Фигме библиотека — **источник**: из макета потом пишут код, и связь между ними держит
человек, поэтому библиотека расходится с продуктом молча. Здесь наоборот: всё на листе **снято с
живого продукта**. Компонент — кроп настоящего элемента; токен — значение, прочитанное из
вычисленных стилей браузера; экран — снимок страницы одним прогоном. Разойтись с кодом такой лист
не может по построению. Пересняли — увидели правду.

Цена честно названа в интервью №057: владелец коробки мышью не двигает. Он смотрит и говорит слово;
раскладку держит правило в коде, а не рука в редакторе. Это ровно та черта, за которую Фигму
ругают (Auto Layout «любят и ненавидят»), и мы её не берём.

## 3. Из чего состоит

```
tools/shoot-flow-map-screens.mjs   съёмщик ЭКРАНОВ   → test-results/flow-map-screens/<id>.png
tools/shoot-design-system.mjs      съёмщик БИБЛИОТЕКИ → test-results/design-system/<id>.png
                                                     → design/flow-map/design-system.json
design/flow-map/flow-map.json      ИСТИНА развёртки: экраны, координаты, связи, ряды
tools/build-flow-map.mjs           сборщик: истина + снимки + библиотека → design/flow-map.html
design/flow-map.html               ЗЕРКАЛО: один самодостаточный файл, снимки вшиты data:URI
```

### 3.1 Съёмщик экранов

Список `ЭКРАНЫ` — единственное место, где перечислено, ЧТО есть приложение. У каждого экрана:
`id` · `имя` · `адрес` · `ждать` (селектор, по которому видно, что экран именно этот) · `группа`
(ряд-процесс) · необязательные `пауза`, `шаги` (клики и ввод — для состояний, в которые адресом не
попасть), `ошибкаОК` (экран 404 снимается нарочно), `уводОК` (экран, который законно уводит).

Два способа положить на лист ложь, оба уже случились и оба закрыты приборно:
- **кадр страницы ошибки под подписью экрана** — теперь код ответа и текст 404 это отказ;
- **кадр чужого экрана под нужной подписью** (молчаливый редирект) — теперь съёмщик сверяет адрес,
  на котором стоит, с тем, куда его звали.

Кадры снимаются одним прогоном, а не берутся готовые из `test-results/`: лист из готовых показывал
бы историю съёмок, а не приложение.

### 3.2 Съёмщик библиотеки

`КОМПОНЕНТЫ` — список кропов: `адрес` + `селектор` (+ `ширина` для десктопных, `шаги`).
Ненайденный компонент попадает в `пропало` и показывается на странице отдельным разделом:
библиотека, молча потерявшая часть, хуже отсутствующей.

Дизайн-схема снимается функцией `СНЯТЬ_СХЕМУ`, исполняемой В БРАУЗЕРЕ: она обходит `cssRules`
всех листов, собирает имена `--токенов` и читает их значения из `getComputedStyle(documentElement)`
— отдельно для светлой и тёмной темы. Плюс типографика с живых `h1`/`h2`/`h3`/`p`.

### 3.3 Манифест — истина

JSON с русскими ключами. Экран: `id · имя · адрес · файл · x · y · заметка`. Связь: `от · к ·
подпись`. Ряд (`полосы`): `имя · y · высота`. Лист: `ширина · высота`.

Координаты — абсолютные, в пикселях листа; экран 390×900 рисуется один к одному. Раскладку
СЧИТАЕТ скрипт (сегодня — одноразовый в чате; вынести в `tools/` — долг, см. §6), по правилам
владельца: ряд = процесс, слева направо по ходу пути, альтернативные состояния над и под
родителем, короче трубопровод.

### 3.4 Сборщик

Чистая функция `собрать(манифест, библиотека) → html`. Внутри:

- **`полосы()`** — разводка труб по коридорам: все трубы, делящие один отрезок (ряд, полку между
  рядами, обход снизу), получают свои номера полос и идут параллельно с шагом `ШАГ_ПОЛОСЫ`;
- **`ломаная()`** — трасса одной трубы тремя случаями: соседи в ряду (прямая), разные ряды (полка
  между рядами), дальние соседи в ряду (обход под рядом — иначе труба шла бы по чужим карточкам);
- **`подробить()`** — точки каждые `ШАГ_УКАЗАТЕЛЯ`, на них SVG ставит `marker-mid` — треугольники
  направления «каждые N»;
- **`труба()`** — ломаная → путь со скруглёнными поворотами;
- **цвет** — по источнику трубы, семь цветов, свои наконечники каждому;
- **подписи** — над горизонтальной трубой; у вертикальной — выноской вбок, как на чертеже;
- **контейнеры групп** — рамка по фактическим границам карточек ряда, плашка-заголовок сверху;
- **страницы** — Развёртка (лист) · Компоненты · Дизайн-схема; панель слева, как в Фигме.

Все стили и скрипт живут ВНУТРИ шаблонной строки сборщика. ⚠️ Обратная кавычка в CSS-комментарии
закрывает строку и роняет сборку молча — это уже стоило прогона.

### 3.5 Зеркало

Один HTML: панорама (`transform` на `#sheet`), зум колесом в точку, клавиши, «вписать», 1:1, тема,
переход по рядам, сворачиваемые виджеты (заголовок · панель · страницы), запрет выделения на
листе. Внешних ссылок ноль — проверяется сборщиком.

## 4. Как этим пользоваться сегодня

```
npm run stand                                  # стенд с эмуляторами
node tools/shoot-flow-map-screens.mjs          # экраны
node tools/shoot-design-system.mjs             # компоненты + схема
node tools/build-flow-map.mjs                  # зеркало
start design/flow-map.html                     # или двойной щелчок
```

Самопроверки: `--selftest` у всех трёх; парные юниты в `tools/*.test.mjs` зовутся из
`npm run test:tools` и стоят в `npm run guards`.

## 5. Как дистиллировать в отдельный продукт

Всё, что знает о NDim, сидит в ТРЁХ местах — и только в них:

| Что | Где | Как отвязать |
|---|---|---|
| Список экранов и состояний | `ЭКРАНЫ` в съёмщике экранов | вынести в конфиг проекта (`screens.json`); съёмщик становится общим |
| Список компонентов | `КОМПОНЕНТЫ` в съёмщике библиотеки | то же: `components.json` |
| Стендовые двери (`?as=`, `?guest=1`) и адрес стенда | адреса в списках | это свойства ПРОЕКТА, они уезжают в конфиг вместе со списками |

Сборщик и зеркало от продукта не зависят: манифест с русскими ключами, снимки, библиотека —
всё общее. Раскладчик (§3.3) надо вынести из чата в `tools/` ДО дистилляции, иначе продукт
получит истину без способа её пересчитать.

Скелет отдельного репозитория:

```
figma-nasha/
  bin/shoot-screens.mjs      ← съёмщик экранов, читает screens.json
  bin/shoot-library.mjs      ← съёмщик библиотеки, читает components.json
  bin/layout.mjs             ← раскладчик: группы и порядок → координаты
  bin/build.mjs              ← сборщик зеркала
  example/                   ← screens.json · components.json · flow-map.json на демо-сайте
  README.md                  ← этот документ, переписанный под чужого читателя
```

Зависимость одна — Playwright. Служб нет. Интернета нет.

## 6. Долги, названные честно

- Раскладчик живёт одноразовым скриптом в чате, а не в `tools/` — истина манифеста пересчитывается
  руками. Первый шаг дистилляции.
- Порог тяжести зеркала не измерен: 39 экранов — 8 МБ. Двести экранов могут стать неоткрываемыми;
  мерить, а не ждать (`researches/66`, вывод 3).
- Админ-панели на листе нет: у стендового пользователя нет клейма админа, а раздел не-админа
  законно уводит на главную. Снимать честно — только под сессией с клеймом.
- Карточка гостя в библиотеке не найдена прибором (селектор) — висит в разделе «Не найдено».
