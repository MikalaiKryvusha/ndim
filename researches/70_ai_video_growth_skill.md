## 2. Локальная разведка — как проект стоит там, куда ляжет эпик

### 2.1 Почему поиск не даёт людей, а ролик может дать (замер, не мнение)

- Поиск: окно 01.07–11.09 — **9 514 показов, 40 кликов** (`MASTER_PLAN.md`, ревизия 2026-09-12).
- Входят через **карточки каталога** по ПРЕДМЕТНЫМ запросам: «джастин бибер», «спелеотуризм»,
  «christy brown» (`researches/67` §5). Человек ищет объект культуры, а не людей.
- Воронка в PostHog за 30 дней: `guest_start` 4, `rating_saved` 4 (`researches/67` §6).

🔑 **Вывод для эпика.** Поисковый человек приходит с намерением «узнать про фильм», и превращать
его в искателя людей — длинный путь. Зритель ролика, дошедший до ссылки, **уже увидел идею
«математика находит людей с похожими вкусами»** и пришёл за ней. Это другое намерение на входе, и
это довод, почему ролики не дублируют SEO, а закрывают другую дыру: **ценность понятна до клика**
(`GOAL.md` → «Критерий пути человека», п. 2). ⚠️ Это гипотеза о намерении, а не замер — её
проверяет метрика эпика (§6).

### 3.4 Как агент проверяет ролик сам, без владельца

- громкость: `ebur128` / `loudnorm print_format=json` → Integrated LUFS и True Peak против порога
  (−14 LUFS — практика авторов; официального числа YouTube/Instagram разведка **не нашла**);
- кадры в точках склеек и по центру → PNG → агент смотрит (обрезанное лицо, мусор в кадре);
- синхрон субтитров: повторное распознавание итога и сверка таймкодов (допуск 100–200 мс — вывод
  разведки, не стандарт); `ffsubsync` (https://github.com/smacke/ffsubsync);
- брак: `silencedetect` (невырезанные паузы), `blackdetect`, `freezedetect`; `ffprobe` —
  1080×1920, 30 fps, длительность.

### 3.5 Проба на этой машине — `whisper` внутри ffmpeg, 2026-09-14 `[TESTED: синтетическая речь]`

Вход: 17,9 с русской речи голосом `Microsoft Irina Desktop` (SAPI). Модель
`ggml-large-v3-turbo-q5_0.bin` (574 МБ, https://huggingface.co/ggerganov/whisper.cpp), лежала в

| Прогон | Время | Результат |
|---|---|---|
| `queue` по умолчанию (3 с) | 13,9 с (с загрузкой модели) | 🔴 «Я сделал **Deep Space**», «где **математики / Африка** находит» — окно режет фразы, модель теряет контекст |
| `queue=30` | **1,1 с** | ✅ «Я сделал Ndim Space, бесплатное пространство, где математика находит людей с похожими вкусами.» — дословно, кроме регистра имени |

🔑 Выводы пробы:
1. **`queue=30` обязателен** — с окном по умолчанию текст непригоден (две смысловые ошибки в трёх фразах).
2. **Имя бренда чинится словарём замен** после распознавания (`Ndim Space` → `NDim Space`): опции
   начальной подсказки у фильтра нет (`ffmpeg -h filter=whisper`).
3. Фильтр отдаёт **фразы, а не слова**. Субтитрам «слово за словом» нужны таймкоды слов — отдельный
   `whisper.cpp` / faster-whisper / WhisperX. Это первый открытый вопрос фазы R&D.
4. ⚠️ Синтетическая речь чище живой: шум, темп и оговорки владельца проба **не проверяла** —
   ворота фазы R&D ставятся на его настоящем сыром ролике.

### 3.5а Таймкоды слов — whisper.cpp `b5130`, та же фраза (`plans/91` Ш2), 2026-09-14 `[TESTED: синтетическая речь]`

|---|---|---|

## 4. Индустрия — органика Reels / YouTube (веб-разведка 2026-09-14)

### 4.1 Как ранжируют сегодня

- **Instagram:** три главных сигнала — время просмотра, лайки на охват, **отправки на охват**
  (отправки весят больше для не-подписчиков) — Моссери, январь 2025
  (https://www.socialmediatoday.com/news/instagram-shares-algorithm-insights-2025/738034/). Цифра
  «отправка в 3–5 раз важнее лайка» — фольклор практиков, официально **не подтверждена**.
- **Оригинальность:** репосты подменяются оригиналом, 10+ репостов за 30 дней выводят аккаунт из
  рекомендаций; новый ролик сначала видит малая пробная аудитория, подписчики приоритета не дают
  (https://www.engadget.com/instagrams-algorithm-overhaul-will-reward-original-content-and-penalize-aggregators-130018977.html ·
  https://techcrunch.com/2026/04/30/instagram-restricts-reach-of-content-aggregators-in-new-crackdown/).
- **Хэштеги:** с декабря 2025 — не больше 5, «помогают поиску, а не охвату»
  (https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/).
  С 10.07.2025 публичные посты профессиональных аккаунтов индексируются поисковиками — **подпись
  ролика работает как SEO-текст** (https://ppc.land/instagram-content-becomes-searchable-on-google-starting-july-10/).
- **Trial reels** — ролик сначала только не-подписчикам, 72 часа
  (https://creators.instagram.com/blog/instagram-trial-reels). Порог «1000 подписчиков» — из
  сторонних гайдов, в справке **не найден**.
- **Shorts:** с 31.03.2025 просмотр = любой запуск, прежняя метрика — `engagedViews`
  (https://ppc.land/youtube-changes-how-shorts-views-are-counted-from-march-31/); Shorts судятся по
  ролику и теме, не по каналу — провал одного не топит канал
  (https://www.tubefilter.com/2024/08/26/rene-ritchie-shorts-creator-faqs/); длительность до 3 минут
  (https://support.google.com/youtube/answer/15424877).
- **Частота:** 3–5 постов в неделю растят подписчиков вдвое быстрее, чем 1–2 (Buffer, 2,1 млн
  постов, https://buffer.com/resources/how-often-to-post-on-instagram/); авторы с 20+ неделями
  регулярности — ~+450 % вовлечения на пост (https://buffer.com/resources/creator-growth-playbook/).
- **Кросс-постинг** одного ролика в Shorts и Reels официально не штрафуется; штрафуются чужие
  водяные знаки — заливать чистый исходник в каждую сеть

## 6. Выводы → последствия для эпика → развилки владельцу

### 6.1 Выводы

1. **Весь монтажный конвейер строится на том, что уже стоит на машине** (ffmpeg 8.1.1 с `whisper` +
   RTX 5070 Ti), плюс `auto-editor.exe` и небольшой Python для субтитров слово за словом и кадра 9:16.
   Docker не нужен. Проба распознавания зелёная на синтетике (§3.5).
2. **Агент проверяет свой монтаж сам** — LUFS, кадры в точках склеек, повторное распознавание,
   `silencedetect`/`blackdetect`, `ffprobe`. Приём агента «транскрипт + кадры в точках решений»
   взят у `video-use`.
3. **Живое лицо владельца — главный актив**, а ИИ-аватары и ИИ-голоса — анти-паттерн и по
   платформам, и по `GOAL.md`. Разрез владельца «снимаю и гружу» совпадает с курсом платформ.
4. **Переход на сайт даёт длинное видео YouTube и профиль Instagram**, короткие ролики — охват.
   Навык обязан выпускать к ролику ссылку с UTM и текст подписи как SEO-текст.
5. **Язык: английский шире** для заказанных площадок, русский — Беларусь/Казахстан/Украина/диаспора.
6. **Горизонт органики — не меньше 20 недель регулярности** (Buffer). Метрика эпика судится по
   ряду, а не по первому ролику.
7. **Платная реклама — поздняя фаза-развилка**: dating-категория, заявки, барьер доступа.

### 6.2 Последствия для эпика

- **Первая фаза — сквозной пилот ОДНОГО ролика** (tracer bullet): гипотеза → сценарий → съёмка
  владельцем → автомонтаж → подпись + UTM → загрузка владельцем. Тонкий срез насквозь вскрывает
  все стыки разом; расширять навык до серии — после.
- **Вид ролика — брендовое решение:** стиль субтитров, плашки, обложка. По канону `AGENT_GUIDE.md`
  → «Дизайн» — **4 варианта**, и естественная форма макета здесь — **четыре рендера пилотного
  ролика** в разных стилях, владелец выбирает на своём же видео.
- **Сценарии и подписи — артефакт владельца** (он их произносит): разведка топов → письмо по
  `AUTHOR_STYLOMETRY.md` → отдельный суд портретом → вычитка владельцем (`GOAL.md` → «Планка бренда»).
  ⚠️ Пара портрета голоса разъехалась (1.1 против 1.2, `STATUS.md` п. 8) — эпик на это наступит.
- **Сырые и готовые видео в git не кладутся** — место на диске вне репозитория, в git только
  сценарии, гипотезы, подписи и метаданные.
- **Метрика эпика** — зритель ролика → переход по UTM → гость → первая оценка. Она сходится с
  «Приоритетом номер 0»: ролик приводит человека в ту же дверь.

### 6.3 Развилки владельцу (интервью)

- **В1. Язык и страны первой волны:** английский · русский · оба (две линейки).
