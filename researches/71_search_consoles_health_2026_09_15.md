## 6. Что этот замер НЕ говорит

- **Сколько страниц в индексе Google.** API Search Console покрытия не отдаёт (`researches/40` §6); «страниц с
  показами» ≠ «проиндексировано».
- **Почему растут позиции Google.** Совпадение по времени с хабами каталога, дверью карточки и текстами — не причина.
- **Что именно Яндекс считает малоценным в карточке.** `LOW_QUALITY` — вердикт без объяснения; гипотеза о тонком
  содержании проверяется только опытом.
- **Почему Bing не показывает проиндексированные страницы.** Две недели индекса — мало для вывода.
