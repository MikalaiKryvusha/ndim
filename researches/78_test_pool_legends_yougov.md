## Источник и что он умеет

**YouGov Ratings** (США): «fame» — доля взрослых, слышавших о вещи; данные ежеквартальные (II кв. 2026), миллионы ответов.
- Карточка вещи (`https://yougov.com/en-us/topics/<movie|tv|game>/<Название>`) — общая узнаваемость среди всех взрослых.
- Разбивка по поколениям (Millennials · Generation X · Baby Boomers; зумеров отдельно нет, есть возраст «18-24») — только
  в списках «самые известные» и только первые 20 строк (`…/ratings/all-time-movies?sortBy=fame&crossBreak=babyboomers`):
  у бумеров «Титаник» 99 %, «Король Лев» 98 %, «Шрек» 99 %. Для отдельной вещи разбивка по поколениям недоступна.
- Поиск и постраничная выдача списков идут через закрытый API страницы — не использовались.

**Граница честности:** источник американский. Слово владельца о «Южном Парке» («бумеры его не знают») американские
числа не подтверждают — 92 % взрослых американцев его знают (больше, чем «Тёмного рыцаря», 84 %); вещь исключена словом
владельца. Российского замера узнаваемости по поколениям в открытом доступе не найдено.

## Правило, выведенное из заказа `[AI]`

Вещь идёт в пул, если её знают **не меньше 80 % взрослых американцев всех возрастов** (все названные владельцем легенды
набирают 84–96 %) **или** её назвал владелец. Для вещи, которая в пуле представляет серию («одна вещь от серии»), берётся
число серии. Прочие правила пула прежние: самые оценённые людьми Пространства, NDim Space Rating ≥ 8, без сенситивных
тем, без вещей «только для своих».
