## Для кого

Человек листает Reels или Shorts. Ему нравятся фильмы, игры, книги или музыка, и ему не хватает
людей, с которыми об этом можно говорить. Приложениями знакомств он, возможно, недоволен, а
возможно, и не пользуется.

## Что проверяем

Зритель, который за 30–60 секунд увидел **живого автора** и **сам экран продукта**, понимает идею
и переходит по ссылке. Довод из разведки: у зрителя ролика другое намерение, чем у человека из
поиска. Поиск приводит на карточку фильма, а ролик показывает саму идею (`researches/70` §2.1).
Платформы в 2026 году поднимают сырое видео от первого лица (§4.3).

⚠️ Вывод агента, не замер. Проверяемых цифр «соло-автор социального приложения вырос на
органике» разведка не нашла (§4.3). Пилот проверяет путь насквозь, а не охват.

## Какой сигнал ждём (как читаем исход)

| Сигнал | Где снимаем | Почему он |
|---|---|---|
| отправки на охват | Instagram API (`instagram_business_manage_insights`) | Моссери: главный сигнал для не-подписчиков (§4.1) |
| доля «досмотрели / пролистали» | YouTube Studio / Analytics API `engagedViews` | удержание первых секунд (§4.1) |
| переходы по ссылке с меткой | PostHog, `utm_campaign=pilot-001` | переход на сайт Instagram API больше не отдаёт (§4.5) |
| гость и первая оценка с меткой | PostHog | метрика эпика (`plans/90`, критерий 4) |

⛔ Порога успеха у пилота нет: один ролик ничего не доказывает (горизонт органики ≥ 20 недель,
§6.1). Исход записывается числами, вывод — после серии.
