## Симптом

Человек открывает ссылку из письма в чистом браузере; ссылка идёт через обработчик
`ndim-space.firebaseapp.com/__/auth/action` и возвращает на `ndimspace.app`. Вход состоялся, экран
верный. В консоли — одна ошибка:

```
requestStorageAccess: Permission denied. @ https://www.google.com/recaptcha/api2/anchor
```

## Что известно — наблюдением

- Источник — **iframe reCAPTCHA** (App Check). Код продукта эту строку не пишет.
- **Только бой:** на стейдже App Check не включён — строки нет (СЛ-12, СЛ-13 на стейдже, консоль чиста).
- **Только после перехода с обработчика ссылки:** смоук двери выката в том же бою (вход кнопкой,
  пять экранов) этой строки не видит — «консоль чиста за весь проход», 2026-09-13 19:5x.
- Прибор шёл с debug-токеном App Check (`tools/lib/app-check-debug.mjs`) и в headless Chromium.
- Вход, профиль и шаг удаления при этом работали — поведение не задето.

## Чего НЕ известно

- Видит ли это живой человек в обычном Chrome без debug-токена, и снижает ли отказ оценку reCAPTCHA
  (то есть не получит ли человек после перехода по ссылке 403 App Check). **Не наблюдалось.**
- Появлялась ли строка до выката №084: переход по ссылке в чистом браузере до него кончался дверью
  входа, но iframe reCAPTCHA грузился и тогда — не проверялось.
