# Bug NEW — гость сохраняет результаты через Google, а Google уже его аккаунт: «создайте аккаунт на другую почту»

**Статус:** 🟡 вылечен на стенде 2026-09-19 — ручной прогон `tools/verify-google-signin.mjs` 0 провалов, мутанты адресно (отчёт `qa/reports/2026-09-19_google-signin.md`); ждёт выката · **Тяжесть:** S2 — человеку советуют завести мусорный
профиль вместо входа в свой · **Заведён:** 2026-09-19 21:13 +03:00, агент — найден ручным проходом путей
Google по заказу владельца («*потрогать своими руками через пути пользоватля, найти баги, и починить*») ·
**Родня:** `bugs/84` (тот же дефект у почты — вылечен состоянием «Эта почта уже Ваша»)

## Симптом

Гость → «Сохранить мои результаты» → «Продолжить с Google» → выбирает Google, у которого уже есть
профиль NDim → красная строка под заголовком «Сейчас Вы гость»: «Этот способ входа уже связан с
другим профилем NDim. Чтобы сохранить текущие результаты, создайте аккаунт на другую почту.»
Кадр: `test-results/google-signin-explore/g3-guest-google-taken.png`.

## Причина

`bugs/84` развёл «гость сохраняет труд» и «человек идёт в свой аккаунт» и завёл состояние `mine?`
(«Эта почта уже Ваша» → «Это мой аккаунт — войти в него» / «Указать другую почту») — но только на
возврате по ссылке. `startGoogle` на тот же отказ `already-in-use` по-прежнему пишет красную строку.
Близнец Google не искался. Выхода «войти в свой аккаунт Google» из-под гостя при этом не было вовсе
(`bugs/NEW_guest_signin_door_has_no_google.md`).

## Фикс

`startGoogle`: отказ `already-in-use` переводит карточку в то же состояние `mine?`, что у почты.
«Это мой аккаунт — войти в него» ведёт в дверь «Вход в Ваш аккаунт», где теперь есть «Войти через
Google». Новых слов нет.

TWINS: искал `already-in-use` на путях привязки — возврат по ссылке (`mine?`, вылечен `bugs/84`),
`startGoogle` (этот баг); прочих путей привязки в `src/routes/profile` нет.

## Решения, принятые без владельца

- `[AI]` Переиспользовано состояние `mine?` с его текстами (решение владельца №007 для почты);
  «на эту почту» в тексте верно и для Google: аккаунт Google — это адрес почты.
