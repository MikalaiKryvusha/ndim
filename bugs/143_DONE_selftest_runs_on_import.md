## Симптом

Новый прибор `tools/check-candidate-descriptions.mjs` импортирует ядро свода
(`measure-wikipedia-overlap.mjs`) и принимает тот же флаг `--selftest`. Запуск

```
node tools/check-candidate-descriptions.mjs --selftest
```

печатал самотест **ЧУЖОГО** прибора — про «Деньги на двоих», «Матрицу» и дискографию Канье, — а
затем выходил кодом 0. Собственный самотест нового прибора не исполнялся **ни разу** и при этом
выглядел пройденным: на экране стояло «✅ самотест пройден».

## Форензика — причина найдена чтением кода, и класс уже назван В ЭТОМ ЖЕ ФАЙЛЕ

`measure-wikipedia-overlap.mjs` объявляет самотест верхним уровнем модуля:

```js
if (process.argv.includes('--selftest')) { … process.exit(bad ? 1 : 0); }
```

Импорт исполняет тело модуля целиком, поэтому чужой `--selftest` в argv запускал этот блок и убивал
процесс до того, как вызвавший успевал что-либо проверить.

🔑 **Класс был известен и записан прямо в этом файле** — шапка сетевой части гласит: «*файл, у
которого есть и экспорт, и работа на верхнем уровне, обязан спрашивать, запустили его или
подключили*». Защищена была ОДНА работа верхнего уровня (сетевой свод) и не защищена ВТОРАЯ
(самотест). То есть правило знали, применили однажды и не прошли по файлу до конца.

⚠️ **Почему это дороже обычной описки:** отказ выглядел как успех. Прибор печатал зелёный
самотест, код возврата был нулевым, и единственной уликой было содержание строк — их надо было
прочитать глазами и узнать чужие.

## Лечение

Признак «запустили или подключили» вычислен ОДИН раз и применён к ОБЕИМ работам верхнего уровня:

```js
const runAsScript = process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href;
if (runAsScript && process.argv.includes('--selftest')) { … }
if (!runAsScript) { /* подключили — отдаём только ядро */ } else { /* сетевой свод */ }
```

## Проверка — наблюдением, оба прибора по отдельности

| Команда | Было | Стало |

| `node tools/check-candidate-descriptions.mjs --selftest` | 🔴 печатал ЧУЖОЙ | 5 случаев ✅, свой |

## Решения, принятые без владельца

1. **Флаг у нового прибора оставлен тем же — `--selftest`.** Соблазн был переименовать его и обойти
   столкновение; это спрятало бы дефект вместо починки, и следующий импортёр наступил бы снова.
   Конвенция флага одна на проект, и чинится причина, а не имя.
