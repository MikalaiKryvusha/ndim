## Симптом

На странице результата теста (`/{lang}/test/{slug}`) список совпадений показывает названия
измерений строкой с обрезкой: длинное название превращается в «Гарри Поттер и философ…».

Закон владельца, произнесённый в тот же день: «названия не должны обрезаться троеточием, всегда
полностью влазят — это закон. если длинное — карточка растет по высоте, чтобы переносящееся на
несколько строк название поместилось».

## Где именно

`src/routes/[lang=lang]/test/[slug]/+page.svelte`, правило `.rows .rname`:

```css
.rows .rname {
  flex: 1;
  min-width: 0;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

## Почему это не «косметика»

Результат теста — это **список того, что у двоих совпало**. Обрезанное название убивает смысл
строки: «Гарри Поттер и…» не отличить от четырёх других частей той же серии, которые лежат в
каталоге рядом (в боевых данных их пять). Человек видит совпадение и не может понять, с чем именно.

Каталог полон длинных имён — это не редкий случай: «Гарри Поттер и Дары Смерти. Часть 2»,
«Пираты Карибского моря: На краю света», «The VVitch: A New-England Folktale».

## Границы — что НЕ является этим багом

- `.share code` в том же файле (строка ~1052) — там обрезается **ссылка-приглашение**, а не имя.
  Обрезка адреса вёрстку защищает и смысла не портит. Не трогать.
- `.segs button` в `src/routes/dims/+page.svelte` — подписи кнопок-переключателей, не названия.
- `.prop .v` в `src/routes/profile/+page.svelte` — значение свойства профиля. Спорно: если там
  окажется имя человека, правило подпадает. Проверить отдельно, **не чинить заодно**.

## Что сделать

1. Убрать `white-space: nowrap` / `overflow: hidden` / `text-overflow: ellipsis` у `.rows .rname`;
   дать строке переноситься, высоте — расти.
2. Выровнять строку по верху (`align-items: flex-start`), иначе оценка справа уплывёт на середину
   многострочного названия.
3. Проверить живым Chrome на 390 и 1440, обе темы: длинное название переносится целиком, соседние
   элементы не разъезжаются.
4. Добавить проверку в страж семейства ТЕСТ (`plans/47`, пишет слабая модель): в собранном HTML у
   `.rname` не должно быть `nowrap`/`ellipsis`. Доказать мутацией.
