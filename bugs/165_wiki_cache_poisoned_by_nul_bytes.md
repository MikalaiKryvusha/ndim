## Половина 1 — кэш сверки отравлен NUL-байтами и лечится только вручную

### Симптом
40 записей каталога стояли в своде как `unverified` («НЕ ПРОВЕРЕНО») и НИКОГДА не вылечивались
повторным прогоном.

### Криминалистика
`tools/measure-wikipedia-overlap.mjs`, `api()`:

```js
if (existsSync(key)) return JSON.parse(readFileSync(key, 'utf8'));   // ← без try/catch
```

Двенадцать файлов кэша **целиком состоят из нулевых байтов** при ненулевом размере (500–587 байт;
файлов нулевого размера в кэше НЕТ вовсе). Подпись оборванной записи на NTFS: размер выделен,
данные не долетели. Битый файл роняет `JSON.parse`, исключение ловится выше по записи, запись
получает `unverified` — и так при КАЖДОМ прогоне, потому что файл на месте и `existsSync` доволен.
**Кэш, который должен ускорять, стал вечной блокировкой.**

### Воспроизведение
```bash
node -e "const fs=require('fs');const f=process.argv[1];const s=fs.readFileSync(f,'utf8');
console.log(fs.statSync(f).size,'байт ·',[...s].every(c=>c==='\u0000')?'ВСЁ NUL':'данные есть')" <ключ>
# → 500 байт · ВСЁ NUL
```

### Замер, разделивший причины (свежий пустой кэш, настоящий прибор, по одной записи)

| Чем был старый кэш | Что дал свежий прогон |
|---|---|
| годен, статья есть (10 записей вне свода) | 10 `clean` |
| годен, поиск пуст (25) | 25 `unverified` — английской статьи не существует, остаток честный |
| кэша не было (3) | 2 `clean` · 1 `copied` |
| **ОТРАВЛЕН NUL (12)** | **10 `clean` · 2 `copied`** |

🔴 **Цена названа числом: два настоящих заимствования лежали невидимыми** —
`tombstone-k5yu2lr0` (ряд 11) и `big-city-greens-k2kyaga6` (ряд 10) — и остались бы такими навсегда.

### Родня по классу
`bugs/131`: сырые байты NUL делали исходник невидимым для `git diff` и `grep`. Класс тот же —
**порча, которая не выглядит порчей**.

## Половина 2 — у английского свода НЕТ живого контроля дороги

`tools/measure-wikipedia-overlap.mjs`:

```js
const LIVE_CONTROL = { slug: 'the-terminator-isl2hxdu', lang: 'ru', minRun: 20 };
if (LANG === LIVE_CONTROL.lang && !ONLY) { … }     // ← для en НЕ выполняется никогда
```

Контроль дороги (поиск статьи → кэш → разбор ответа) существует ровно потому, что дорога однажды
сломалась МОЛЧА: обрезанный ключ кэша сваливал все статьи в один файл, и прогон честно печатал
«97 чистых». Это записано в комментарии самого прибора.
🔴 **Все английские своды шли без этой защиты** — включая тот, на котором стоит работа троих
разработчиков по 512 записям.

Связь с половиной 1 прямая: живой контроль на английском поймал бы отравленный кэш в первом же
прогоне, потому что известная копия перестала бы опознаваться.

## Половина 3 — ворота печатают ЧУЖОЙ зелёный самотест и выходят кодом 0

`tools/rewrite-catalog-descriptions.mjs`:

```
:145   if (process.argv.includes('--selftest')) { … process.exit(…) }   // ← без предохранителя
:175   if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) { … }
```

Предохранитель «запустили или подключили» накрывает рабочий режим (:175), но НЕ самотест (:145),
а :145 стоит РАНЬШЕ. `tools/gate-rewrites.mjs` импортирует отсюда `checkEdit` — значит самотест
писаря срабатывает при импорте, до собственной проверки аргументов ворот.

### Наблюдение (не чтение кода)
```
$ node tools/gate-rewrites.mjs --selftest
  ✅ случай 1 … ✅ случай 5
  ✅ самотест пройден: 5 случаев
  код выхода: 0
```
**Ворота не отработали ни разу и отчитались зелёным.** Спросивший «здоровы ли ворота» получает
зелёный от ДРУГОГО прибора. Это ложный зелёный в чистом виде.

### Образец фикса лежит рядом
`measure-wikipedia-overlap.mjs:233` уже сделан правильно и несёт объяснение, почему:
```js
const runAsScript = process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href;
if (runAsScript && process.argv.includes('--selftest')) { … }
```
Класс ловится в проекте уже **пятый** раз за двое суток («файл, у которого есть и экспорт, и работа
на верхнем уровне, обязан спрашивать, запустили его или подключили»).

## ✅ ФИКС — сделан одним заходом

- [x] **1.** `api()`: чтение кэша в `try/catch`; битый файл **удаляется и перекачивается**, а не роняет прогон.
- [x] **2.** Годность записи проверяется РАЗБОРОМ, а не только `existsSync`.
- [x] **3.** Запись кэша **атомарна** — во временный файл рядом + `rename`. Оборванная запись больше
      не притворяется годной: `rename` в пределах тома либо случился, либо нет.
- [x] **4.** `LIVE_CONTROL` → словарь `LIVE_CONTROLS` по языкам; английский контроль заведён
      (`corrective-measures-akp4cezf`, порог 40 при измеренных 50). Язык БЕЗ контроля теперь
      **останавливает прогон**, а не пропускается молча, — молчаливый пропуск и был дефектом.
- [x] **5.** `rewrite-catalog-descriptions.mjs`: `runAsScript` объявлен ДО самотеста и накрывает
      оба режима.
- [ ] **6.** Разовая уборка кэша главной копии (12 отравленных файлов) — НЕ сделана намеренно:
      это чужой рабочий каталог. Прибор теперь лечит их сам при первом же прогоне, поэтому уборка
      перестала быть обязательной. Оставлено Менеджеру одной строкой.

🔴 **Правило перевеса записано в ШАПКУ прибора, а не только сюда:** тот, кто вылечит последнюю
копию языка, придёт чинить упавший контроль и прочитает шапку — документ бага он читать не будет.

### Мутации — адресаты названы ДО прогона, каждая проверена В ОБЕ СТОРОНЫ

| Мутация | Исправный прибор | Мутированный |
|---|---|---|
| Подложен файл из NUL-байтов на `corrective-measures-akp4cezf` (509 Б, всё NUL) | ⚠️ «запись кэша испорчена, перекачиваю» → `copied`, **ряд 50** | `try/catch` обезврежен → **НЕ ПРОВЕРЕНО: 1** (работа спрятана, как в бою) |
| Снят `en` из `LIVE_CONTROLS`, прогон `--lang en` | ✅ «живой контроль (en): опознан копией (ряд 50 слов)» | ❌ «ДЛЯ ЯЗЫКА „en“ НЕ ОБЪЯВЛЕН ЖИВОЙ КОНТРОЛЬ», **код 1** |
| Снят `runAsScript` из строки самотеста писаря | `node tools/gate-rewrites.mjs --selftest` → «нужен журнал прогона», **код 1** | «✅ самотест пройден: 5 случаев», **код 0** — ворота не отработали и отчитались зелёным |

Все три мутации откачены, файлы сверены побайтово (`diff -q`).

## Берётся ли класс стражем — ответ ЗАМЕРОМ (вопрос Менеджера)

**Да, берётся.** Признак механический: файл в `tools/` имеет `export` на верхнем уровне И работу на
верхнем уровне (чтение `process.argv`), но НЕ имеет предохранителя «запустили или подключили».

Замер по 180 файлам `tools/`: форму класса несут **14**, предохранитель есть у **6**, **нет у 8**:
`check-candidate-descriptions` (чинит dev-3) · `deploy` · `measure-catalog-drift` ·
`measure-catalog-tags` · `team-status` · `team-workplaces` · `verify-contour-parity` · `verify-stage-clean`.

🔑 **Все восемь СПЯЩИЕ, а не живые:** ни один из них сегодня не импортируется другим прибором
(проверено грепом импортов) — дефект просыпается в ту минуту, когда кто-то захочет переиспользовать
экспорт. Ровно это и случилось дважды за сутки: с писарем (этот баг) и с приёмкой кандидатов.

⚠️ **И честная граница будущего стража, оплаченная прямо здесь.** Первая редакция моего зонда
обвинила `tools/review.mjs` — а у него предохранитель ЕСТЬ, просто написан ДРУГОЙ формой
(`resolve(process.argv[1]) === resolve(fileURLToPath(import.meta.url))` вместо `pathToFileURL`).
То есть страж этого класса обязан знать ОБЕ формы, иначе он сам станет источником ложного красного —
и это ровно та ошибка, против которой он пишется. Канон об этом уже предупреждает:
«сторожи полными формами, а не короткими подстроками» (`BUG_FIXING_FRAMEWORK.md` → «Стражи»).
