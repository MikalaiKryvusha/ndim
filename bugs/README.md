# `bugs/` — дефекты, трудности, поломки

По одному документу на дефект: симптом, детерминированное воспроизведение, форензика, корневая
причина/гипотезы, история починки, статус. Собственный долговечный беклог багов агента — ничего не теряется,
любой баг можно поднять с нуля будущей сессией. По одному `NN_<имя>.md` на баг.

**Для владельца:** можете завести баг простыми словами (что не так, как воспроизвести) — агент
структурирует. Просматривайте директорию, чтобы видеть известные дефекты и их статус.

**Для ИИ-агента:** наткнулся на дефект в работе/тестах — заводи документ по канону (навык `/report-bug`;
метод — `BUG_FIXING_FRAMEWORK.md`), даже мелкий. Документ бага несёт наблюдаемый критерий приёмки
фикса — что будет ВИДНО работающим после починки (`REQUIREMENTS_FRAMEWORK.md`). Пока открыт — без тега
`DONE`. Починен **и проверен** — `git mv NN_x.md NN_DONE_x.md` и добавь раздел
`## ✅ СТАТУС: DONE (дата + время)` — заголовок кириллицей «СТАТУС» (замер Интегратора
2026-08-29: 36 документов по-русски против 5 латиницей; латинская форма была наследием
шаблона, а не решением), а слово закрытия — `DONE`, то же, что тег имени файла (замер
Интегратора смены 10: `СТАТУС: DONE` — 50, `СТАТУС: ЗАКРЫТ` — 0; прежняя редакция этой
строки предписывала слово, которого в живом корпусе не было ни разу, — снята его замером). 🔑 Не переименовывай руками — зови
`node tools/close-bug.mjs <NNN> --proof "<чем доказано>"`: он делает `git mv`, дописывает секцию
и ОТКАЗЫВАЕТ без доказательства лечения. Правило без команды здесь уже не работало — восемь
вылеченных багов смен 7–8 остались открытыми все до одного (`EXP-0227`).
После 3 неудачных слепых попыток фикса — стоп и переход к
исследованию (`/bug-research`).

**Поддиректория `bugs/KAIF/`** — дефекты и запросы улучшений о самом **фреймворке KAIF**, а не об
этом проекте. Когда провал прослеживается к дыре в KAIF (правило, которое увело не туда;
отсутствующее ограждение; сломавшаяся машинерия) — заводи там по тому же канону багов, **строго
по-английски** (эти документы адресованы разработчику KAIF). Перед заведением — дедупликация:
сначала ищи в `bugs/KAIF/`; развёртывание с привязкой к origin ищет и в трекере истока и шлёт
подтверждённые сигналы наверх (у нас — в соседний проект `D:\work\ai_sandbox\KAIF`, см.
`AGENT_GUIDE.md` → контур «чиню локально, сообщаю наверх»), отвязанное — держит всё локально.
