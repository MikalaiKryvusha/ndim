## Симптом

`npx playwright test e2e/demo.spec.ts` — кейс «мост в гостя: кнопка приходит после звёзд, ведёт в гостя и не оставляет
записи истории» на проекте `mobile` падает на строке 84:

```
Error: expect(locator).toBeVisible() failed
Expected: visible · Error: element(s) not found · timeout 5000ms
> 84 | 	await expect(bridge).toBeVisible();
```

Замер 2026-09-25: прогон всего файла — 1 провал из 10 (mobile); `-g "мост в гостя" --repeat-each 3` — mobile 1 провал из 3,
desktop 0 из 3 (вывод этого замера видел только чат сессии, в файл не сохранён). Строка адреса моста (89) в прошедших
прогонах зелёная на обеих ширинах. ⚠️ Было ли падение ДО правки адреса двери (`839255a`) — не проверено: в пользу
«не связано» только то, что кейс падает на строке 84, раньше строки адреса.

## Воспроизведение

`npx playwright test e2e/demo.spec.ts -g "мост в гостя" --repeat-each 3` — на mobile ожидаемо ≥ 1 провал.

## Гипотезы (не проверены)

1. **Касание раньше гидратации.** Тест зовёт `click()` на кнопке звезды сразу после `goto('/ru')`; кнопка есть в
   пререндере, а обработчик Svelte навешивается позже. На mobile-эмуляции гидратация дольше — касание уходит в
   разметку без обработчика, звезда не ставится, мост не приходит. Если так — это ещё и вопрос продукта: ранний тап
   живого человека тоже теряется молча.
2. Анимация появления демо-блока на узкой ширине перекрывает кнопку в момент клика.

## Решения, принятые без владельца

Нет. Починка не начата: найден по ходу другой задачи (место входа гостя), правило «один баг за раз».
