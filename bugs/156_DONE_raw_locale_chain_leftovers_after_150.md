## Улики — файл и строка

1. 🔴 **`src/routes/profile/+page.svelte:301–305`** — `displayName`:
   ```ts
   const displayName = $derived.by(() => {
     const first = data?.values.name?.first;
     const nick = data?.values.name?.nick;
     return first?.[lang] ?? first?.ru ?? nick?.[lang] ?? nick?.ru ?? null;
   });
   ```
   Это **МЁРТВЫЙ КОД**: `displayName` не читается нигде в файле (греп по файлу — только
   объявление). Опасен он не работой, а формой: это дословно та цепочка, которую `bugs/150`
   убил, — `??` ловит отсутствие, а не пустоту, и по замеру того бага карточка самого
   владельца несёт `first.ru=""` при заполненном `en`. Первый, кто «оживит» перемен­ную,
   воскресит «мёртвую душу» на экране профиля. Класс описан в ЭТОМ ЖЕ файле десятью строками
   ниже (`:310–319`): «перенося блок, проверяй… что он не тащит за собой отменённое».
2. **`src/routes/space/+page.svelte:306`** — живой код, имена новых измерений в ленте
   «Сегодня»: `dim.title[lang] ?? dim.title.ru ?? dim.id`. Замер `bugs/150` по каталогу дал
   «заперто пустой строкой: 0», поэтому симптома нет; но правило «лестница одна на продукт»
   это место обходит.
3. **`src/routes/dims/+page.svelte:705`** — живой код, определение вида карточки:

## Почему это класс, а не три опечатки

`bugs/150` оплатил урок: «одна цепочка на продукт», потому что копии расходятся молча.
Три пережившие копии — это три места, где следующая правка локалей разойдётся с продуктом.
Прецедент воскрешения отменённого в этом же файле уже был (`profile/+page.svelte:310`:
строка «В Пространстве с …» возвращалась дважды).
