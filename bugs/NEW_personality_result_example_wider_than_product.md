## Корневая причина

Пример написан по макету V5 (№029), где панель собирала факты; в разработке панель стала списком оценок, а пример не
сверили с тем, что строит страница. Класс — «текст шире продукта» (тот же, что «привычки» в этом же тесте, `b878d9b`).

## Лечение — на выбор, тексты через вычитку владельца

2. Панель дорастает до примера (группировка по виду, «оценили ещё N») — работа по макету, числа из каталога.
