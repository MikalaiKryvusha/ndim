## Симптом — словами владельца

> «*не появился ТЕСТ. Потому что dims_list не синхронизирован — да?*»

Он одобрил кандидата в панели, измерение легло в каталог, а в списке комнаты его не было: счётчик
показывал прежние **5111**.

## Замер — гипотеза владельца верна, но лаг больше, чем он думал

Зонд по боевой базе, 2026-08-17 ≈20:11 UTC:

| Что | Значение |
|---|---|
| Измерение в коллекции `dims/` | **ЕСТЬ**, `time.created` 20:09:01 UTC |
| Записей в индексе `dims_list` | **5111** — ТЕСТА в индексе НЕТ |
| Документов в коллекции `dims/` | **5123** (5122 измерения + служебный индекс) |
| Отметка сборки индекса | `built: { at: 2026-08-02T12:57Z, docs: 5112 }` |
| Лог боевого контейнера, 25 циклов подряд | «грязных точек нет — пересчитывать нечего» |

**Расхождение — 11 записей:** десять одобренных владельцем кандидатов и тестовая.

## 🔴 Причина — ранний выход цикла, найдена чтением кода

`sync-server/index.mjs:1054`:

```js
if (!fullPass && ready.length === 0) {
  log('грязных точек нет — пересчитывать нечего');
  await reportServer(startedAt, { lastSuccessAt: startedAt });
  return 0;                       // ← выход
}
…
const indexedDims = await ensureDimsIndex(dimsCount);   // ← строка 1095, СЮДА НЕ ДОХОДИТ
```

**Обслуживание индекса стоит НИЖЕ выхода из холостого цикла.** Значит индекс обновляется только в
том цикле, где есть грязная точка, то есть **когда кто-то из людей поставил оценку**. Активных за
7 дней — ноль. Новое измерение ждёт ночного полного прохода (00:00 UTC), то есть **до 24 часов**.

🔑 **Почему это важнее, чем кажется.** Комната читает список ОДНИМ запросом к индексу — по прямому
указанию владельца об экономии запросов. То есть индекс это не кэш, а единственный источник списка:
чего нет в индексе, того для комнаты и для экрана «Измерения» не существует.

🔴 **И это бьёт ровно в цель эпика.** Его слова, ради которых комната строилась: «*чтобы мы новые
хайповые объекты культуры БЫСТРО заливали в пространство… сегодня весь мир на хайпе от одиссеи
Нолана, а мы такой кусок поисков пропускаем мимо нас*». Механизм заведения работает за минуту, а
попадание в каталог ждёт до суток.

⚠️ **Отметка `built.at` от 2026-08-02 — НЕ улика простоя.** Когда каталог не менялся,
`ensureDimsIndex` честно выходит по `built.docs === dimsCount`, не трогая отметку. Пятнадцать дней
тишины означают, что измерений не заводили, — и это правда.

## Как снят симптом (разово, причина цела)

Перезапуск боевого контейнера: `docker restart ndim-server-prod`. При старте `pointsCache === null`,
поэтому `warmup = true` и `fullPass = true` — цикл проходит мимо раннего выхода.

```
[sync 20:12:44] прогрев кэша при старте: в Пространстве точек — 342
[sync 20:12:45] индекс каталога дополнен: +11, стало 5122 измерений
```

Проверено зондом после: в индексе 5122, ТЕСТ на месте.

⚠️ Раздел оставлен как ОСНОВАНИЕ выбора, а не как открытая развилка: выбор сделан ниже.

| Путь | Что делает | Цена |
|---|---|---|
| **A. Обслуживать индекс ДО раннего выхода** | перенести `ensureDimsIndex` выше строки 1054 | `count()` по `dims/` каждый цикл: ~6 единиц чтения × 1440 циклов ≈ **8,6 тыс. чтений в сутки** (17 % суточной квоты) ради события, которое случается раз в день |
| **B. Флаг «каталог изменился»** | комната ставит отметку при создании и одобрении; холостой цикл читает ОДИН документ | **1440 чтений в сутки** (2,9 % квоты). ⚠️ Заводит пару «истина ↔ зеркало», которая может разъехаться |

сомнении всегда может сверить числа — то есть зеркало самопроверяемо.

## 🔵 ВЫБОР СДЕЛАН ВЛАДЕЛЬЦЕМ 2026-08-18 — интервью №039, В4

Это **путь B с частотой часового такта**, а не минутного: обслуживание индекса становится

против 2,9 % у рекомендации агента и 17 % у пути A. Реакция: до часа вместо суток.

🔑 **Почему он выбрал не A из моего списка, а свою формулировку, и почему это лучше моего ответа.**
Я предлагал выбирать частоту опроса при НЕИЗМЕННОМ минутном такте — то есть решал этот баг в
отрыве от `bugs/152`, где тот же минутный такт и есть повод переделки. Владелец соединил их одной

рядом. Класс ошибки — **чинить симптом внутри рамки, которую соседняя работа уже сносит**.

## Смежное, что этот баг делает видимым

Даже попав в индекс, новое измерение **не появляется на публичном сайте**: страницы статические, и
каталог вмораживается в HTML на сборке. Это территория `plans/57` (автопересборка). То есть у
«быстро залить хайповую новинку» два узких места, и это — первое из двух.
