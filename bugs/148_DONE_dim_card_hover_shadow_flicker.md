## Симптом — словами владельца

> «*Когда на карточки измерений курсор наводишь, какая-то тень внутри карточки исчезает, снаружи
> карточки появляется — не нравятся мне эти тени. Карточка чуть-чуть поднимается вверх — это ок,
> пускай, но тени убери, они криво сделаны, мерцают как-то странно резко, бесят.*»

## Форензика — почему «внутри исчезает, снаружи появляется»

Карточка несёт `class="card dim"`, то есть общий `box-shadow: var(--card-shadow)`. И этот токен —
**ДВЕ тени сразу**, что и объясняет его формулировку дословно:

```css
/* тёмная тема */
--card-shadow: 0 0 0 1px rgba(63, 217, 255, 0.06),   /* волосяное кольцо — читается «внутренней» */
               0 24px 60px rgba(2, 8, 20, 0.6);      /* большая мягкая — «снаружи» */
```

На наведении менялись **три величины разом**: `border-color`, `transform: translateY(-1px)` и обе
тени в переходе `box-shadow 0.18s`. Подъём сдвигает обе тени, кольцо в 1px при этом
перерисовывается по субпиксельной сетке — отсюда резкость. На экране таких карточек десятки.

## Лечение

У `.dim` тень снята — и в покое, и на наведении, — и убрана из перехода: анимировать то, чего нет,
значит тратить кадры впустую. Осталось ровно то, что владелец оставил: подъём на 1px и подкраска
рамки.

⚠️ Правка **адресная**, на `.dim`. Общий `.card` держит тень для остальных экранов, где владелец
её не отвергал: правило одного экрана не переносится на продукт молча.

## Решения, принятые без владельца

1. **Подъём оставлен ровно как был** (`translateY(-1px)`) — он сказал «это ок, пускай».
2. **Подкраска рамки оставлена** — про неё он не говорил, и снимать её значило бы забрать отклик
   наведения целиком.
3. **Четыре макета не рисовались:** это не выбор формы, а снятие названного дефекта по прямому
   указанию с однозначным исходом.
