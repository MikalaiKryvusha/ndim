## Вектор цели

- **Achieve:** у сервера синхронизации появляется дверь того же рода, что у приложения: выкат
  проходит только через неё, и она умеет отказать.
- **Maintain:** боевая служба продолжает работать всё время постройки — пульс не прерывается ·
  замороженная копия остаётся ОТДЕЛЬНОЙ рабочей копией (⛔ не переводить службу на рабочее дерево
  «чтобы проще», `plans/83`).
- **Avoid:** выкат пятнадцати коммитов этим планом · «дверь, которая молчит» — ворота, не
  умеющие покраснеть, красят зелёным непроверенное (`TESTING_FRAMEWORK.md`).

## Критерии приёмки (Scale · Meter · Target)

1. **Дверь отказывает грязному дереву.** Meter: мутация — незакоммиченная правка в `sync-server/`,
   запуск двери · Target: код выхода ≠ 0, служба НЕ тронута, пульс прежний.
2. **Дверь отказывает по красному тесту.** Meter: мутация — заведомо падающий `npm run test:sync`
   · Target: код выхода ≠ 0, до перезапуска службы дело не дошло.
3. **Дверь отказывает по мёртвому пульсу.** Meter: мутация — служба поднимается, но пульс не
   идёт · Target: дверь красная и **сама откатывает** на прежний коммит.
4. **Расписка на коммит.** Meter: `git -C <замороженная копия> rev-parse HEAD` · Target: совпадает
   с коммитом, на который выписана расписка.
5. **Откат одной командой.** Meter: живой прогон отката после успешного выката · Target:
   замороженная копия вернулась на прежний коммит, пульс жив, время отката записано числом.
6. 🔴 **Ручной функциональный прогон** (`TESTING_FRAMEWORK.md`, слово владельца 2026-09-12):
   дверь прогоняется РУКАМИ на полном цикле — выкат, проверка пульса прибором, откат. Юнит и
   мутация маркер `[NOT-TESTED]` не переворачивают.
7. **Отчёт прогона существует** — `qa/reports/<дата>_sync-server-deploy-door.md`, семь полей,
   `node tools/verify-test-reports.mjs` зелёный.
