## Вектор цели (по `REQUIREMENTS_FRAMEWORK.md`)

- **Achieve:** у NDim появляется поверхность ТЕСТ — страница-инструмент со своим адресом, куда
  человек приходит по «тестовому» запросу, получает честный результат БЕЗ аккаунта и уносит его
  ссылкой. Это крупнейший измеренный спрос из всех достижимых: RU «тест личности» 219 453,
  «тест на характер» 95 445, «тест на совместимость» 62 467 (`researches/30` + §16
  `researches/34`); выдачу держит 16personalities — структурный аналог, а не конкурент по нише.
- **Maintain:** честность инструмента — результат из настоящей математики, а не Барнум
  (`researches/30` §7.4 — наше отличие); инварианты: числа похожести не публикуются нигде
  (№018 В4 + №023), шеринг результата — БЕЗ чисел; никаких обещаний трафика раньше зимы
  2026/27; язык человека, не продукта (урок C.1).
- **Avoid:** дублировать интерактив лендинга (граница с `plans/21` зафиксирована метапланом:
  тот остаётся на месте, тест — самостоятельная поверхность) · решать механику и форму за
  владельца (это видение: интервью + 4 макета) · эссе-кластеры вокруг теста (§7.1: AI
  Overviews съедают их первыми — выживает ИНСТРУМЕНТ).

## Критерии приёмки фазы (Scale · Meter · Target)

1. **Механика утверждена.** Scale: развилка владельца · Meter: интервью с вариантами и
   рекомендацией, `npm run questions` · Target: ответ получен и разнесён с цитатой «интервью
   №NNN, ВN» в этот план.
2. **Форма утверждена.** Scale: 4 макета страницы · Meter: кадры `shoot-mockups` + страница
   вычитки, поднятая ДО доклада (`EXP-0125`) · Target: владелец выбрал один (возможно с
   правками).
3. **Инструмент живёт без стены.** Scale: путь гостя до результата · Meter: живой Chrome, обе
   темы × 390/1440, `?as=none` · Target: человек БЕЗ аккаунта доходит до результата; ни одной
   формы до ценности (канон `ideas/09`).
4. **Содержание — в сыром HTML.** Scale: собранная страница · Meter: греп по `build/` (по
   образцу `verify-dimension-pages`) · Target: заголовок, вопросы/шаги и тексты результата
   читаются в HTML без JS.
5. **Шеринг без чисел похожести.** Scale: то, что уносится ссылкой/картинкой · Meter: страж
   грепом по разметке результата · Target: ни процента похожести, ни порядка близости в
   шеримом артефакте; страж доказан мутацией.
6. Всё новое `[NOT-TESTED]` до прогона; стражи доказаны мутациями до доверия (`EXP-0082`).
