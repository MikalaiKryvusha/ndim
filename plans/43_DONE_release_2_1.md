## Критерии приёмки

1. **Запись честная.** Scale: строки «что нового» · Meter: каждая строка трассируется на
   выкаченный факт (журнал ниже) · Target: ни одной строки о будущем или невыкаченном.
2. **Текст — голос владельца.** Scale: RU+EN тексты · Meter: чеклист §7 `AUTHOR_STYLOMETRY` +
   вычитка владельцем страницей · Target: владелец утвердил (возможно с правками).
3. **Версия согласована всюду.** Scale: package.json · виджет версии · история версий ·
   Meter: `npm test` (тесты формата версии) + живой Chrome «Меню»/«О системе» · Target: 2.1.0
   с номером сборки, без расхождений.
4. **Выкат по регламенту** (метрика витрины → полный каталог → гейты → чистая сборка → deploy →
   прод-стражи) — как в `plans/39` (веха выката 2026-08-14 — образец).
