## Вектор цели

- **Achieve:** двенадцать решений собраны в ОДНУ страницу интервью, каждое — вопрос, на который
  можно ответить одним кликом, не открывая ни одного другого документа.
- **Maintain:** форма вопроса — класс-правило владельца: **понятно, просто, по делу, без воды, с
  примером**. Жаргон агента в вопросе = «не понимаю».
- **Avoid:** «см. выше» и отсылки между вопросами (он не будет скроллить) · номера вместо
  названий · вопрос без предложения внутри · страница, которую агент сам не открыл и не посмотрел.

## Критерии приёмки (Scale · Meter · Target)

1. **Вопросов на странице.** Scale: число вопросов · Meter: `node tools/questions-guard.mjs` ·
   Target: 12, каждый со своим адресатом ответа.
2. **Каждый вопрос самодостаточен.** Scale: число вопросов, содержащих отсылку «см. выше» / «как
   в вопросе N» / ссылку на документ вместо изложения · Meter: вычитка текста страницы ·
   Target: **0**.
3. **Каждый вопрос несёт предложение агента внутри.** Scale: число вопросов без варианта,
   рекомендованного агентом, с доводом · Meter: та же вычитка · Target: **0**.
4. **Названия, не номера.** Scale: число заголовков вопросов, начинающихся с номера бага ·
   Meter: вычитка · Target: **0** — имя работы первым, номер только скобкой после.
5. 🔴 **Страница открыта агентом ДО доклада.** Meter: `node tools/review.mjs open interviews/…` +
   агент сам смотрит поднятую страницу глазами (снимок кадра) · Target: агент видел страницу
   целиком; **«не смей мне такое дерьмо больше открывать» — цена невыполнения этого пункта**.
6. **Страница проходит контур.** Meter: `npm run questions` · Target: ждущих интервью 1,
   вопросов вне `interviews/` не прибавилось.

1. 🔴 **Двенадцать вопросов разом — много для одного присеста.** Смягчение: порядок в таблице —
   от дорогого к дешёвому, и страница честно говорит в шапке, что отвечать можно порциями и
   сверху вниз. Дробить на две страницы — хуже: тогда часть вопросов снова начнёт копиться.
2. **Макеты для `16`/`19` могут не успеть.** Тогда эти два вопроса честно снимаются со страницы,
   а не подаются без макетов. Правило четырёх макетов сильнее желания закрыть пункт.
3. **Соблазн изложить вопрос ссылкой на баг.** Владелец не открывает документы агента, чтобы
   ответить на вопрос. Ссылка допустима как «подробности», изложение — обязательно внутри.
