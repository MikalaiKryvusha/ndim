## Вектор цели (по `REQUIREMENTS_FRAMEWORK.md`)

- **Achieve:** каждая индексируемая страница NDim отвечает на ИЗМЕРЕННЫЙ интент и несёт ≥3
  самостоятельных слоя данных ЛИБО осознанно ждёт их накопления вне индекса (`researches/34` §5.2).
- **Achieve:** ни одной страницы-сироты — каждая публичная страница достижима ≤3 кликов от
  главной и несёт ≥3 внутренних входящих ссылки (§6.3).
- **Achieve:** поверхность ТЕСТ (крупнейшая измеренная, §2.2) существует и находится.
- **Maintain:** инварианты владельца — числа похожести не публикуются нигде · соседство измерений
  отсутствует · конкуренты не называются · отзывы настоящие · обложек нет (§2.3).
- **Avoid:** доля «несамодостаточных» страниц не растёт бесконтрольно — site-wide профиль качества
  (§4.3) управляется данными, а не надеждой.

## Критерии приёмки эпика (Scale · Meter · Target)

1. **Покрытие индекса известно и отслеживается.** Scale: % страниц каталога в индексе Google ·
   Meter: прибор панели притока (фаза 1), отчёты в `researches/` · Target: ≥3 датированных замера,
   тренд назван.
2. **Сироты устранены.** Scale: внутренние входящие ссылки на страницу каталога · Meter: прибор
   карты ссылок по `build/` · Target: 100 % страниц ≥3 входящих, глубина ≤3 кликов.
3. **Спрос добран.** Замеры Т0 (виды тестов), Т3 (группа D: «объект + рейтинг/похожие»), Т10
   (боль/одиночество) лежат в `researches/` с датами.
4. **Каждая НОВАЯ страница отвечает запросу с замеренной частотностью > 0** (наследие `plans/34`).
5. **Инварианты — стражами с доказанными мутациями:** ни числа похожести, ни данных другого
   человека, ни блока соседства на публичных поверхностях (страж `verify-dimension-pages` уже
   стережёт часть — расширить на новые поверхности).
6. **Вердикт по каталогу записан** после ≥3 месяцев данных панели: держать / порог / переработка —
   с числами покрытия и показов, по заранее записанным критериям фазы 8.
7. **Тексты для людей** — через `AUTHOR_STYLOMETRY.md` §7; терминология по словарю.
8. Каждая закрытая фаза — `/fable-judge`; полная регрессия зелёная.
