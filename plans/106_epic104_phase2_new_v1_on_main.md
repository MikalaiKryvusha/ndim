   - Действие. Страница загружается; человек не прокручивает.
   - Результат. Видны: знак и имя, переключатель RU/EN, тема, «Войти»; надзаголовок «Знакомства нового измерения»;
     заголовок А; подзаголовок; ссылка «Пройти тест на совместимость ↓»; три портрета с пузырями.
   - Проверка. Кадры 2 адреса × 2 ширины × 2 темы в `test-results/new-landing-v1/`, прочитаны глазами; e2e
     `landing.spec.ts` зелёный.
2. **Демо на объектах каталога.**
   - Ситуация. Тот же человек прокрутил до теста.
   - Действие. Ставит звезду «Матрице».
   - Результат. Строка горит его числом; карта, проценты трёх карточек и карточка для сторис пересчитаны ядром
     (`computeRelation`); появляется поп-ап «самая сильная связь» и кнопка «Смотреть больше» с волнами.
   - Проверка. e2e `demo.spec.ts`; кейс набора НЛ-демо.
3. **Ранний тап не теряется.**
   - Ситуация. Страница ещё не гидратирована (сеть придержана на загрузке скриптов).
   - Действие. Человек касается звезды.
   - Результат. Звезда горит сразу; после гидратации демо считает с этой оценкой.
   - Проверка. e2e с придержанными `_app/immutable/*.js`; кейс НЛ-ранний-тап.
4. **Звёзды демо становятся оценками гостя.**
   - Ситуация. Человек без сессии оценил три объекта демо.
   - Действие. Нажимает «Смотреть больше».
   - Результат. Заведён гость; в `points/{uid}/dims` ровно три документа с его значениями; `guest_start` несёт `entry`

   - Проверка. Ручной прогон на стенде и стейдже, запись в базе прочитана; отчёт `qa/reports/2026-09-25_new-landing-v1.md`.
5. **Двери для своих и письма.** Вошедший на `/`, `/ru`, `/en` уводится в `/profile` под щитом; ссылка из письма

6. **Стражи, тесты и смоук переписаны тем же коммитом.** `npm run check`, `npm test`, `npm run guards`, `npm run e2e`
