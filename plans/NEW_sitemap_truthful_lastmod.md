## Вектор цели

- **Achieve:** карта сайта несёт `<lastmod>`, которому Google может верить: дата последнего значимого изменения
  страницы.
- **Maintain:** карта пререндерится, как сейчас (`src/routes/sitemap.xml/+server.ts`); выкат — только `npm run deploy`;
  сборка из чистого клона без сети не ломается.
- **Avoid:** дата сборки у всех страниц; дата, которая сдвигается у страниц, чьё содержание не менялось; дата «из
  будущего».

## Первоисточники (прочитаны 2026-09-25)

- Google, «Build and submit a sitemap»: «*Google uses the `<lastmod>` value if it's consistently and verifiably (for
  example by comparing to the last modification of the page) accurate.*» · «*The `<lastmod>` value should reflect the
  date and time of the last significant update to the page.*» · «*an update to the main content, the structured data, or
  links on the page is generally considered significant, however an update to the copyright date is not*» · «*Google
  ignores `<priority>` and `<changefreq>` values.*» — https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap
- sitemaps.org: «*This date should be in W3C Datetime format. This format allows you to omit the time portion, if
  desired, and use YYYY-MM-DD.*» · «*the date must be set to the date the linked page was last modified, not when the
  sitemap is generated*» — https://www.sitemaps.org/protocol.html
- Заметка Google 2023 «Sitemaps ping endpoint is going away» тело не отдала — на неё не опираюсь.

## Замер источников даты (2026-09-25 22:25:38–22:25:48 по журналу сессии; бой, публичный каталог, анонимный вход и его удаление)

- **Запись каталога, поле `time.updated`** — у пробы `2025-04-03T11:23:12Z`, то есть время 1.x. Переписывания текстов
  2026 года его не двигали. **Лжёт** о содержании страницы.
- **Метаданные документа `updateTime`** (есть в ответе REST у каждой записи) — 5154 записи по дням: 2026-08-15 — 4018,
  2026-08-17 — 881, 2026-09-05 — 171, дальше единицы. Это любая запись в документ: и текст, и рейтинг (он в JSON-LD
  карточки — значимо), и невидимые технические теги (`techTags` — незначимо). Правдив примерно, с шумом.
- **Тексты страниц — в общих файлах:** `src/lib/content/docs.ts` (все документы, генерирует `tools/extract-docs.mjs`),
  `src/lib/content/test-copy.ts` (все три теста). Дата последнего коммита файла сдвинула бы все страницы вида, когда
  правили одну.

## FORK

`FORK: options <А: дата из источника по виду страницы (запись каталога — updateTime; тексты — последний коммит файла) |
Б: реестр по отпечатку значимого содержания собранной страницы | В: lastmod только у карточек по updateTime, у прочих —
нет> · price of error <lastmod, который врёт хоть у части страниц, Google перестаёт использовать для всей карты
(«consistently»); у А — общий файл сдвигает все страницы вида, updateTime шумит от техтегов; у Б — новый шаг выката и
чтение реестра по сети; у В — дешевле всех, шум updateTime остаётся, тексты без свежести> · consulted <Google «Build and
submit a sitemap», sitemaps.org; замер источников выше> → рекомендация Б, решение — Менеджера.`

**Б подробно.** После сборки для каждого адреса карты берётся отпечаток того, что Google называет значимым: видимый текст
основного содержания, JSON-LD и ссылки страницы (без метки сборки, года копирайта и прочего служебного). Реестр
`{адрес: {отпечаток, дата}}` выкладывается рядом с картой (`/sitemap-lastmod.json`) на каждом контуре. Следующий выкат
читает реестр того контура, КУДА катит: отпечаток прежний — дата прежняя; другой — дата выката. Первый выкат: реестра нет —
`lastmod` не пишется ни у кого (правдиво; даты появляются с первыми изменениями), либо засев карточек по `updateTime` —
второе решение Менеджера. Реестр не прочитался — карта уходит БЕЗ `lastmod`, и никогда не «всем сегодня». Страж: дата ≤
момента сборки; у страницы с прежним отпечатком дата не сдвинулась; у изменённой — дата выката.
Где живёт шаг: реестр знает, куда катят, — значит шаг в двери выката (`npm run deploy`, зона Менеджера) или в сборке с
названным контуром; решать Менеджеру.

## Лестница (после решения FORK)

1. Функция отпечатка страницы (чистая, юнит: служебное не меняет отпечаток, текст/JSON-LD/ссылка — меняют).
2. Шаг реестра и штамп `lastmod` в собранной карте (юнит: прежний отпечаток — прежняя дата; отказ чтения — без `lastmod`).
3. Стенд: две сборки подряд — даты не сдвинулись; правка одной карточки — сдвинулась ровно у неё.
4. Стейдж: выкат дважды, карта и реестр прочитаны с контура. Заявка.
