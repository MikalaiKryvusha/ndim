**Вектор цели** (слово владельца 2026-08-22: «*строим 3 стенда*»): у каждой роли команды —
свой изолированный стенд (порты выводятся из имени рабочего каталога), одновременно подняты
до ТРЁХ; конкуренция за замок стенда исчезает для эмуляторных работ, замок остаётся только
настоящим синглтонам (Docker сервера синхронизации, бой, стейдж, дверь выката).

**Критерии приёмки эпика:**
1. Три стенда трёх ролей живут ОДНОВРЕМЕННО, и это доказано замером (память, все три отвечают,
   сиды независимы).
2. Роль поднимает свой стенд без правки конфигов руками — слот выводится из каталога.
3. e2e и стражи роли ходят на ЕЁ порты; чужой стенд не красит их и не подменяет сборку
   (обе мины разведки закрыты: `reuseExistingServer` на чужой preview · чужие эмуляторы на 8181).
4. Литералы портов в приборах стережёт страж (по образцу `stand-cleanup.test.ts`), доказанный
   мутацией.
5. Канон сшит: манифест (замок = синглтоны, лимит «≤ 3 поднятых»), `AGENT_GUIDE` (EXP-0027 →
   «e2e требуют погашенного СВОЕГО стенда»), досье окружения.

## Решения владельца (2026-08-22, дословно — «строим 3 стенда. Сейчас машина занята игрой ещё
## запущенной. Без игру будет сильно легче. И файл подкачки можно расширить, если что»)

| Решение | Следствие |
|---|---|
| Парк = **3 одновременных стенда** | лимит операционный (правило + проверка при старте), слоты портов получают ВСЕ роли |
| Файл подкачки — **условное добро** («если что») | расширяем ТОЛЬКО если замер трёх стендов упрётся в потолок фиксации; не превентивно |
| Игра держит ~5,7 ГБ транзиентно | замеры фазы 1 повторить и «без игры» — числа разведки снимались при ней |

## Опора — разведдок dev-2 (сдан 2026-08-22, вердикт чисел: пересчитан частично QA)

## Чего эпик НЕ делает

- Не трогает Docker-контейнеры сервера синхронизации, бой и стейдж — они синглтоны под замком
  как были.
- Не расширяет файл подкачки превентивно (условие владельца «если что» — только по упору замера).
- Не заводит вторую машину и не переносит стенды в облако.
- Не отменяет статус-доску: строка «что делаю» остаётся, умирает только очередь за эмуляторами.
