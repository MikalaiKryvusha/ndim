## Вектор цели (Avoid → Maintain)

Ответ владельца не уходит в пустоту: страница, которая больше не может записать ответ (сервер умер, документ переписан,
страницу закрыл агент), говорит это сама и не даёт писать дальше; черновик владельца не теряется и возвращается в новую
страницу того же документа; агент закрывает живую страницу только командой, которая отказывает, пока владелец пишет.

## Критерии приёмки (из постановки)

1. Сервер страницы убит → за ≤ 15 с страница перекрыта плашкой «эта страница больше не принимает ответы», ввод
   заблокирован; при возврате на вкладку — проверка сразу.
2. Документ переписан при живом или перезапущенном сервере → старая страница гаснет той же плашкой с кнопкой «открыть
   новую редакцию»; `/decision` от страницы чужой редакции — отказ 409 с текстом ответа на странице (Copy).
3. Черновик: новая страница того же документа ставит на место ответы на вопросы с тем же текстом; ответы на изменённые
   вопросы — блоком «черновик прошлой редакции» с их текстом (ничего не пропадает молча).
4. `review close <doc>`: печатает порт · pid · документ; отказывает кодом 4, пока владелец печатал < 180 с назад, странице
   < 180 с или черновик не сохранён; иначе просит СВОЙ сервер страницы закрыться (токен из замка); `--force` только с
   `--owner-word "<дословно>"`.
5. Второй `open` того же документа при живой странице окна не поднимает («уже открыта: адрес»); при мёртвой — поднимает
   на ПРЕЖНЕМ порту (тот же адрес — черновик и старая вкладка возвращаются); порт занят — сказано вслух.
6. Строка плашки «ответы вернутся на места сами» — только там, где это правда (прежний порт); `AGENT_GUIDE.md`
   «Наш контур такой команды не имеет» — поправка на месте.
7. Набор `qa/suites/review-stale-tab.md` → ручной прогон живым браузером (сервер убит → плашка; новая редакция → старая
   гаснет; черновик переехал; close отказывает/закрывает) → отчёт `qa/reports/2026-09-2x_review-stale-tab.md` + мутации.
   Регресс: `node tools/verify-bug110.mjs` зелёный.

## Риски

- (а) Фоновая вкладка: Chrome душит таймеры скрытой вкладки до раза в минуту — проверка на `visibilitychange`/`focus`
  закрывает окно «вернулся и сразу печатает»; `/decision` отвергает чужую редакцию — последний рубеж.
- (а) Ложная плашка при кратком сбое — два промаха подряд, а не один; возврат связи снимает плашку сам.
- (б) Прежний порт занят чужим процессом — новая страница на другом адресе, черновик туда не переедет; старая вкладка
  держит его и показывает текстом с Copy; `open` говорит это вслух.
- (в) Пачка (`review batch`) — один сервер на очередь; замок `_queue`, редакция — у каждой страницы документа своя.
