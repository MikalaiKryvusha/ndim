## Цель фазы

Сделать так, чтобы **добавление одного измерения стоило одной-двух операций Firestore, а не 5111
чтений**, и чтобы обслуживание индекса перестало молча терять данные. Это техническое предусловие
всего остального эпика: пока пересборка индекса стоит как весь каталог и стирает поля, любой код,
создающий измерения, строится на песке.

Попутно закрывается открытый `bugs/106` — правка живёт в той же функции, и чинить её отдельным
заходом значит платить за пересборку боевого образа дважды.

## Критерии «готово»

1. Добавление измерения в каталог **не вызывает полного перечитывания каталога** — доказано
   прибором «до/после» в числах операций.
2. Документ каталога без поля `title` **не вводит вычислитель в вечную пересборку** — доказано
   воспроизведением на стенде до фикса и его отсутствием после.
3. Полная пересборка (аварийный путь) **сохраняет поля записи, которых не знает** — доказано
   тестом, красным на сегодняшнем коде.
4. `space/stats.dims` равно числу записей индекса; диаметр Пространства при 5111 измерениях
   равен **714,9** (`bugs/106`).
5. Страж фазы **красный на сегодняшнем коде** и доказан ≥2 мутациями.
6. `npm test`, `npm run test:calc`, `npm run test:rules` — зелёные.
7. Пара «истина ↔ зеркало» вписана в реестр `AGENT_GUIDE` с однострочной командой проверки.

## Чего эта фаза НЕ делает

- **Не строит панель и не пишет ни строки клиента.** Инкрементальная запись со стороны панели
  приезжает в фазе 4 вместе со своим единственным потребителем — формой создания (YAGNI).
- **Не меняет поведение экранов** «Измерения» и «Пространство» — числа обязаны остаться теми же,
  кроме исправленного `dims` (5112 → 5111) и диаметра (715 → 714,9).
- **Не выкатывает.** Правка живёт в образе сервера синхронизации; пересборка и выкат — рука
  владельца (`npm run calc:image`).
