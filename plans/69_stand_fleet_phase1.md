### 1. 🔴 Мина `reuseExistingServer` — в ТОЧНОЙ форме

`node_modules/playwright/lib/runner/index.js:821–832`, Playwright 1.61.1:

```js
const isAlreadyAvailable = await this._isAvailableCallback?.();
if (isAlreadyAvailable) {
  if (this._options.reuseExistingServer)
    return;                                   // ← ВЫХОД
  throw new Error(`… is already used, make sure that nothing is running on the port/url …`);
}
if (!this._options.command) throw …
launchProcess({ command: this._options.command, … })   // ← сюда уже не доходит
```

**`return` стоит ВЫШЕ `launchProcess`, а `webServer.command` у нас — `npm run build && npm run
preview` ОДНОЙ строкой** (`playwright.config.ts:45`). Значит при живом сервере на 4173 не
запускается не только preview — **не запускается СБОРКА**. Код роли не компилируется вовсе, и
прогон судит артефакт, к которому её правка никогда не прикасалась.

🔑 **И вторая половина:** при `reuseExistingServer: false` Playwright бросает громкую ошибку с
именем порта. То есть наша настройка `true` не «упрощает жизнь» — она **превращает точный отказ
в молчаливый прогон не по тому артефакту**.

### 2. Что видит сосед — обе стороны, и опасна ВТОРАЯ

| Случай | Что видит роль | Куда она идёт |
|---|---|---|
| Её правка **исправна**, на 4173 висит сборка соседа без этой правки | **КРАСНОЕ**, падения разнородные и задевают экраны, которых правка не касалась | чинить исправный код |
| Её правка **сломана**, сборка соседа была здоровой | 🔴 **ЗЕЛЁНОЕ** | сдавать сломанное с зелёным e2e |

**Опаснее вторая строка:** это `EXP-0091` («осиротевший preview отдаёт СТАРУЮ сборку») с чужим
worktree в роли источника. Первая уже описана в `STATUS.md` капканом 2 ровно этой приметой —
«падения РАЗНОРОДНЫЕ и задевают экраны, которых правка не касалась».

### 3. Почему `--strictPort` обязателен — и почему слот его НЕ заменяет

`npm run preview` — это голое **`vite preview`**: без `--port`, без `--strictPort`. Порт берётся
из умолчания vite 8.1.4 (`DEFAULT_PREVIEW_PORT = 4173`); в `vite.config.ts` порт не задан вовсе.
Без флага занятый порт не роняет запуск, а тихо переезжает на соседний — и дальше preview роли
сидит на 4174, а `webServer.url` смотрит в 4173, где отвечает ПРЕЖНИЙ сервер со старым списком
файлов. Страж краснеет «404 на `_app/immutable/…`», и это выглядит дефектом продукта.

⚠️ **Слот эту мину не лечит.** Слот разводит РОЛИ по разным портам; `--strictPort` защищает от
СВОЕГО вчерашнего сироты на СВОЁМ порту. Два разных отказа — флаг нужен при любом слоте.

### 4. Приборы, поднимающие preview руками — их всего два, а инструкций девять

**Спавнят сами:** `tools/deploy.mjs:378` и `tools/verify-admin-home.mjs:105` — **оба уже с

КОММЕНТАРИИ-ИНСТРУКЦИИ тоже.** Страж, глядящий только на исполняемый код, оставит без охраны
