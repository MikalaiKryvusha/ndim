## Вектор цели (Achieve)

Боль: наша страница вопросов умирает вместе с чатом, и ответ, который владелец печатал, пропадает
(капкан `STATUS.md`; наш сигнал в исток — issue #64, `bugs/KAIF/14`). Цель: владелец отвечает на готовой
странице KAIF — «Сохранить» плавает справа сверху, живые вопросы сверху, ответ переживает упавший
сервер страницы, страницу нельзя закрыть снаружи, пока он печатает, — и при этом НЕ теряет ничего из
того, что наша страница умела по его словам: голос Silero `eugene` (интервью №011, В1 = Д), тихие
часы 23:00–09:00 (№011, В3 = А), отказ поднять вопрос, отсылающий наружу (его правило 2026-08-15:
«*Пиши прямо в вопросе то, что предлагаешь взять*»).

## Критерии приёмки

1. **Команда.** Ситуация: в `interviews/` лежит интервью со статусом «ждёт». Действие: агент запускает
   команду показа из `AGENT_GUIDE.md` → «Место вопросов». Результат: открывается окно готовой страницы
   KAIF. Проверка: `package.json` → `review` ведёт на `.kaif/tools/contour/review.mjs` (или обёртку над
   ним); снимок экрана показывает окно.
2. **Голос.** Ситуация: страница поднята днём. Результат: звучат гудки, затем голос `eugene` называет
   документ. Проверка: строка сигнала в выводе называет `eugene`; владелец подтверждает словом, что услышал.
3. **Тихие часы.** Проверка: `.kaif/kaif.json` → `contour.quietFrom` = `23:00`, `contour.quietTo` = `09:00`;
   прогон самотеста тихих часов генератора зелёный.
4. **Отсылка наружу.** Ситуация: вопрос содержит «см. выше». Действие: команда показа. Результат: страница
   НЕ поднимается, печатается лечение. Проверка: мутант-интервью с «(выше)» → отказ; чистое → показ.
5. **Ответ переживает сервер.** Ситуация: страница открыта, сервер убит. Действие: «Сохранить». Результат:
   следующий `--queue --list` подбирает ответ с `recovered: true`. Проверка: запись в
   `interviews/decisions/<док>.decision.json`.
6. **Страж вопросов** `npm run questions` видит ответы, записанные готовой страницей (статусы, разнос).
7. **Ручной функциональный прогон** записан отчётом `qa/reports/<дата>_shipped-review-page.md`: обе темы,
   две ширины, путь «открыть → ответить → сохранить», путь «сервер умер → сохранить → подобрано».
