# Домашка 11 — включить вход в проекте `ndim-stage` (два клика в консоли)

> **Создана:** 2026-08-15 · **Родитель:** `plans/53_EPIC_stage_environment.md` фаза 1 ·
> **Статус:** 🔴 ждёт владельца · **Время:** ~2 минуты ·
> **Исходящее:** после клика агент доводит настройку сам и проверяет замером

## Почему это не может сделать агент

Агент попробовал программный путь и получил отказ платформы — замер, а не предположение:

```
POST identitytoolkit.googleapis.com/v2/projects/ndim-stage/identityPlatform:initializeAuth
→ 400  BILLING_NOT_ENABLED : Identity Platform feature requires billing to be enabled.
```

То есть завести вход **через API** умеет только платный Identity Platform. На бесплатном плане
Spark, где мы сознательно держим стейдж (Ваше условие «нам нужно оставаться в бесплатном плане»),
вход поднимается **первым открытием раздела в консоли** — и это единственная кнопка во всём эпике,
до которой агент дотянуться не может.

## Что сделать

1. Открыть: **https://console.firebase.google.com/project/ndim-stage/authentication**
2. Нажать **«Начать»** / **Get started** — это и есть то, чего не может API.
3. Во вкладке **Sign-in method** включить три способа, ровно те же, что в бою:
   - **Google**
   - **Email/Password** → внутри включить **Email link (passwordless sign-in)**
   - **Anonymous** (гостевой режим — на нём стоит весь наш онбординг)

Больше ничего трогать не нужно: домены, шаблоны писем и остальное агент доведёт сам и проверит.

## Как агент поймёт, что готово

Он прочитает конфигурацию тем же API (`admin/v2/projects/ndim-stage/config`) и сверит три поля:
`signIn.anonymous.enabled` · `signIn.email.enabled` · `signIn.email.passwordRequired = false`.
Пока раздел не открыт, API отвечает `CONFIGURATION_NOT_FOUND` — то есть проверка честная и
подделать её нечем.

## Альтернатива, если не хочется кликать

Включить на `ndim-stage` план Blaze с тем же платёжным аккаунтом — тогда агент заведёт вход сам.
Счёт при этом остался бы нулевым (стейдж живёт внутри бесплатных квот), но проект перестал бы быть
бесплатным **буквально**, а Вы просили именно буквально. Поэтому по умолчанию — клик.
