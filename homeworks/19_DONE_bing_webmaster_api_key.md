## Зачем

У Google и Яндекса агент читает статистику сам. У Bing — нет: ключ выдаёт только сама консоль и только хозяину
сайта, поэтому этот шаг — Ваш. Прибор `tools/bing-snapshot.mjs` уже написан и ждёт ключа. Bing ответит на то,
чего не говорит Google: **сколько наших страниц вообще лежит в индексе**.

## Шаги

1. Откройте **https://www.bing.com/webmasters** и войдите.
2. Проверьте, что сайт `ndimspace.app` в списке (он там с 11 июля, заводили импортом из Google).
3. Справа вверху — шестерёнка **Settings** → раздел **API Access**.
4. Если открываете впервые — примите условия.
5. Нажмите **Generate API Key** и скопируйте ключ.

## Куда положить ключ

**Лучше всего — сами, в файл**, тогда ключ не попадёт в переписку:
откройте `D:\work\ai_sandbox\ndim\.env` и допишите одной строкой в конец

```
NDIM_BING_WEBMASTER_KEY=сюда_ключ
```

Если так неудобно — пришлите ключ в чат, я положу его туда же. Ключ только читает статистику, но всё равно
это ключ к Вашей учётной записи Bing.

⚠️ Ключ один на всю учётную запись: если когда-нибудь нажать **Delete** и создать новый — старый перестанет
работать, и прибор скажет «нет ключа».

## Что будет дальше

Скажите «положил». Агент сам снимет первый снимок Bing (`node tools/bing-snapshot.mjs`) и допишет его в разведку
консолей. Первый прогон ещё и проверит допущение прибора: он построен на JSON-протоколе Bing, а старые протоколы
SOAP и POX Bing отключал 31.08.2026.
