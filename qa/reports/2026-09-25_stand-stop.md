## Решения, принятые без владельца

- `[AI]` Корень — самый верхний предок, чья строка — запуск стенда (`stand-launch.mjs` · `emulators:exec` ·
  `npm … run stand`). Обёртка Git Bash `bash.exe … npm run stand` поэтому гасится целиком: она и есть запуск стенда.
- `[AI]` Конфиг слота убирается после остановки: лаунчер убирает его сам только при штатном завершении, а после
  `taskkill` файл оставался.

## Границы (GAP)

- **Прогоны `stand-launch --exec` своего рабочего места** гасятся тоже: у них тот же `emulators:exec -c <свой конфиг>` — это
  своё, и так и названо.
- **Сирота `node sync-server/index.mjs`** после одиночного убийства `stand.mjs` командой не находится: у сироты нет ни пути
  конфига, ни живого предка-запуска (класс `bugs/103`). Её ищут по имени процесса и строке, исключая сам поиск, — EXP-0081.

- **Стенд, поднятый без конфига слота в строке** (не через `stand-launch.mjs`: руками `firebase emulators:start`),
  командой не опознаётся — «гасить нечего».
- **Не Windows** — команда отказывается: Win32_Process и `taskkill`.
- **Слот 0 (главная копия)** — живьём не гонялся: запрет трогать стенд Менеджера; юнит «чужой конфиг выбирает только
  чужое дерево» судит развилку и для него.
