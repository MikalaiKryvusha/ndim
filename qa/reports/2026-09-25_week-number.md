## Карточка прогона

- **Работа:** прибор числа недели для ставки 1 метаэпика `plans/104` (слово владельца — интервью №096, В3 = А:
  «*Раз в неделю Вы получаете одно число*»). Пять чисел людей недели: пришли · гостем · ≥ 5 оценок · Связи ·
  вернулись в 1–7 день. Общий помощник запроса — `tools/lib/posthog.mjs`.
- **Контур:** бой — PostHog проекта NDim Space, события с `properties.env = 'prod'`; прибор только читает (личный ключ
  чтения из `.env`), в продукт и базу не пишет.
- **Прогонов:** 2026-09-25 +03:00:
  · 01:42 первые три прогона (`--week 2026-09-14`, `--week 2026-09-21`, `--week 2026-10-05`) — третий упал кодом
    127 (`process.exit()` при живом соединении fetch, известная ловушка Windows) → выход переведён на `process.exitCode`;
  · 01:43 недели `2026-08-24`, `2026-08-31`, `2026-09-07` → «пришли 0» на неделях до 2026-09-05: снят момент появления
    признака `env` (HogQL `min(timestamp) WHERE properties.env = 'prod'` → 2026-09-05 19:26:40 +03:00), прибор печатает
    предупреждение на таких неделях;
  · 01:43 неверный вход `--week 2026-13-01` молча стал 2027-01-01 → проверка даты и понедельника;
  · 01:44:40 полный набор НВ-01…НВ-05 одной серией: `node tools/week-number.mjs --week <W>` для
    2026-09-14 · 2026-09-21 · 2026-10-05 · 2026-09-07 · 2026-08-31 · 2026-13-01 · 2026-09-15 (вывод —
    `week-runs.txt` в скретчпаде сессии);
  · 01:45 сверка «вернулись» с первоисточником: HogQL — людей с событиями в ≥ 2 разных дня за 2026-09-14…09-27 → **0**.
- **Проверок:** пройдено 5 (НВ-01…НВ-05) · провалено 0 · не исполним 1 (НВ-06 — возвратов в данных ноль).
  - Гигиена: юнитов у прибора нет (читающий прибор над живым источником; самотест не заведён — заморозка новых
    приборов №096 В2 = А разрешает этот прибор словом владельца В3, но не дополнительную машинерию вокруг него).
  - Функциональный прогон: бой · прибор запущен руками на живых данных, вывод прочитан глазами · НВ-01 pass (пришли
    160, гостем 9, ≥ 5 оценок 3, Связи 6, вернулись 0 — окно открыто до 28.09) · НВ-02 pass (7 · 0 · 0 · 0 · 0) ·
    НВ-03 pass (код 3, Node не падает) · НВ-04 pass (предупреждение на 2026-08-31, нет на 2026-09-07) · НВ-05 pass
    (обе ошибки входа, код 1) · НВ-06 **не исполним** — возвратов в данных ноль (сверено HogQL), положительный случай
    «вернулись > 0» ещё не наблюдался.
- **Найдено:** три дефекта прибора в ходе прогона, все вылечены до сдачи: падение Node кодом 127 на выходе · слепота
  к неделям до 2026-09-05 без предупреждения · неверная дата превращалась в другую. Дефектов продукта — ноль.
  Наблюдение о мире: с 14 сентября ни один человек не заходил в Пространство NDim Space в два разных дня.
- **Следы:** нет — прибор только читает PostHog; учёток, записей, событий прогон не оставил.
- **Вердикт:** **pass** в границах: число недели снимается одной командой с контролем на неделе ролика; строка
  «вернулись» проверена только на честном нуле (НВ-06 ждёт первого возврата); `person_id` склеивает устройства одного
  человека только после входа; приход на главную пишет строка без SDK со случайным идентификатором на визит — человек
  только с главной считается в «пришли» каждым визитом, и «вернулся» для него не измерим (`plans/105` Б3).
