## Тест-план

**Что проверяется.** Новая главная из утверждённого макета `design/new-landing-v1.html` на трёх адресах и её тест на
совместимость: первый экран, числа, вопросы и ответы, подвал; тест на объектах каталога; перенос звёзд теста в NDim ID
гостя; двери для своих (вошедший, ссылка из письма); счёт прихода.

**Основание ожиданий** (откуда взяты ожидаемые результаты):
- №096 В5 — структура новой V1 «*сама структура нравится, утверждаю*»; №096 В6 = Б — новый лендинг становится главной,
  «*язык выбирается переключателем вверху*»; №096 В15 = А — заголовок; №096 В16 = А — 12 вопросов;
- №096 В14 — демо: «*смесь ТОП фильмов, сериалов, качеств … до 10 штук, … компактно по вертикали список*»;
- №096 В8 = А — «*нужны честные изменения, которые реально внутри продукта будут*»: звёзды теста = оценки гостя;
- №009 В2 — карта связей и звёзды «*прямо перед глазами*»; №009 В3 — вход гостем не называется кнопкой, «Смотреть
  больше» пульсирует и испускает волны; №010 Р8 — «*Лендинг только для новых*»;
- №058 В1 = А — разведка, где «молчаливое угадывание языка» и «пустой для робота корень» — худшие решения;
- `plans/106` — критерии приёмки 1–6 и развилки (язык главной, запись оценок на мосту, пустой старт, ранний тап).

**Техники.** Классы эквивалентности: адрес (`/` · `/ru` · `/en`) × сессия (нет · маркер · ссылка из письма) × ширина
(390 · 1440) × тема (светлая · тёмная). Граничные значения: ноль оценок перед мостом · одна оценка · звезда 10 ·
повторное касание той же звезды. Переходы состояний теста: пусто → оценено → снято → мост → гость → «Связи».
Угадывание ошибок: касание до гидратации · двойное нажатие моста · сеть оборвана при записи · англоязычный браузер на `/`.

**Сознательно НЕ покрыто и почему.** Настоящий встроенный браузер Instagram (нет устройства с приложением; риск и
решение — фаза 4 `plans/104`) · вход Google до конца (нет тестового аккаунта) · поведение в бою до слова владельца о
выкате · вкус текстов — судит владелец вычиткой (интервью №097).

## Чек-лист прогона (порядок)

1. Гигиена: `npm test` · `npm run test:tools` · `npm run guards` · `npm run check` · `npm run e2e` (стенд погашен).
2. Кадры: сборка → `npx vite preview --port 4173 --strictPort` → `node tools/shoot-new-landing.mjs` → кадры
   `test-results/new-landing-v1/` прочитаны глазами (НЛ-01…НЛ-10).
3. Стенд: `npm run stand` → НЛ-12, НЛ-13, НЛ-14, НЛ-15 руками с чтением базы эмулятора.
4. Стейдж: `npm run deploy -- --stage` (ворота смоука на стенде) → на `ndim-stage.web.app` НЛ-01…НЛ-19, телефон и
   десктоп, обе темы; база стейджа и PostHog прочитаны.
5. Отчёт `qa/reports/<дата>_new-landing-v1.md` — семь полей, две строки «Гигиена» и «Функциональный прогон».
