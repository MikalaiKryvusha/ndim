# Набор «число недели» — прибор `tools/week-number.mjs`

> **Создан:** 2026-09-25 (агент Opus 5.5) · **Родитель:** `plans/105_epic104_phase1_texts_faq_eyes.md` шаг Б1 ·
> метаэпик `plans/104` критерий 1 · **Статус:** живой набор · **Исходящее:** —

**Основание ожиданий.** Слово владельца — интервью №096, В3 = А: «*Раз в неделю Вы получаете одно число*».
Определения пяти чисел — шапка прибора. Базовая линия недели ролика 002 — аудит 2026-09-25 (≈150 приходов,
гостем 10, оценивших 6, аккаунт 1).

**Покрыто:** контроль прибора на неделе с людьми · пустое окно · неделя до появления признака `env` · неверный вход
(не дата, не понедельник) · выход кодом без падения Node. **Сознательно не покрыто:** склейка одного человека с двух
устройств (`person_id` PostHog — граница прибора); сверка «вернулись» с живым человеком (за окна прибора возвратов 0 —
положительный случай возврата ещё не наблюдался; см. НВ-06).

| № | Кейс | Шаги | Ожидаемо |
|---|---|---|---|
| НВ-01 | Контроль: неделя ролика | `node tools/week-number.mjs --week 2026-09-14` | «пришли» > 0 (ролик 19–20.09); гостем, ≥ 5 оценок, Связи — дробью «N из пришли»; код 0 |
| НВ-02 | Обычная неделя | `--week 2026-09-21` | пять строк дробью; «окно возврата открыто», пока не прошло 14 дней; код 0 |
| НВ-03 | Пустое окно | `--week 2026-10-05` | «пришли 0» + предупреждение о контроле; код 3; Node не падает |
| НВ-04 | Неделя до признака `env` | `--week 2026-09-07` | предупреждение «раньше 2026-09-05…» не печатается (окно начинается позже); на `--week 2026-08-31` — печатается |
| НВ-05 | Неверный вход | `--week 2026-13-01` · `--week 2026-09-15` | «такой даты нет» · «не понедельник»; код 1 |
| НВ-06 | Возврат считается | неделя, где человек заходил в 1–7 день после первого | «вернулись» > 0 — **ждёт первого наблюдаемого возврата**; до него признак проверен только на отсутствии |
