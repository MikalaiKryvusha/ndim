# Набор «число недели» — прибор `tools/week-number.mjs`

> **Создан:** 2026-09-25 (агент Opus 5.5) · **Родитель:** `plans/105_epic104_phase1_texts_faq_eyes.md` шаг Б1 ·
> метаэпик `plans/104` критерий 1 · **Статус:** живой набор · **Исходящее:** —

**Основание ожиданий.** Слово владельца — интервью №096, В3 = А: «*Раз в неделю Вы получаете одно число*».
Определения пяти чисел — шапка прибора. Базовая линия недели ролика 002 — аудит 2026-09-25 (по бою: 152 пришли
на главную, гостем 9, оценивших 6, аккаунт 1; поправка 2026-09-25 02:25 — прежние «≈150, гостем 10» несли события стейджа).

**Покрыто:** контроль прибора на неделе с людьми · пустое окно · неделя до появления признака `env` · неверный вход
(не дата, не понедельник) · выход кодом без падения Node · 🆕 2026-09-25 (`bugs/NEW_DONE_week_number_window_labelled_utc_is_moscow.md`):
пояс окна — неделя по Москве, подпись «+03:00», начало окна сверено самим HogQL (НВ-07) · общая дорога HogQL отказывает
границе времени без пояса до сети (НВ-08). Основание НВ-07/НВ-08 — документация PostHog: «*Date literals parse in your
project's timezone, not UTC … pass the timezone explicitly*» (posthog.com/docs/sql/expressions). **Сознательно не покрыто:** склейка одного человека с двух
устройств (`person_id` PostHog — граница прибора); сверка «вернулись» с живым человеком (за окна прибора возвратов 0 —
положительный случай возврата ещё не наблюдался; см. НВ-06).
