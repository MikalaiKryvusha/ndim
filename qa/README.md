# `qa/` — артефакты QA-миссии

Здесь живут документы, по которым ведётся тестирование продукта: карта путей человека, тест-план,
наборы и чек-листы. Заказ владельца (2026-08-15): «*Нужно, чтобы ты покрывал тестами пути
пользователей*». Эпик — `plans/54_EPIC_qa_mission.md`, обзор индустрии — `researches/38_qa_mission.md`.

**Единица покрытия — путь человека, а не модуль и не дефект.** У пути есть идентификатор
`NDIM-<ОБЛАСТЬ>-<NNN>`; на него ссылается разметка `// @covers NDIM-…` в самих проверках, и по ней
машина считает покрытие. Ручных реестров «путь → проверка» здесь не бывает: они разъезжаются за
месяц.

| Документ | Что отвечает | Состояние |
|---|---|---|
| `JOURNEYS.md` | Какие пути человек проходит в продукте — карта и единица покрытия | 🔧 фаза 0, первая редакция |
| `TEST_PLAN.md` | Охват, уровни глубины, группы, ворота, риски | фаза 1 |
| `suites/` | Наборы по областям: что именно проверяется в каждой | фаза 1 |
| `checklists/` | Выпуск, вёрстка, приватность — там, где полный кейс дороже своей пользы | фаза 5 |
| `JUDGE_CHECKLIST.md` | 🆕 Что судья делает ДО, ВО ВРЕМЯ и ПОСЛЕ суда — в командном режиме. Каждый шаг оплачен промахом суда, цена стоит рядом с шагом | живой справочник |
| `team-verdicts.md` | Вердикты QA по порциям ролей — по одному на суд, с двумя числами в шапке | живой журнал |

**Уровни глубины прогона** — `Smoke` (жива ли сборка, потолок 10 минут) · `CP` Critical Path
(работает ли то, ради чего продукт существует) · `Ext` Extended (краевое и редкое). Это НЕ уровни
ISTQB: те — про стадию разработки, эти — про то, какой поднабор запускается сейчас.

**Группы по исходу** — `позитив` (валидные данные) и `негатив` (неверный, враждебный, краевой вход).
Позитивное закрывается первым — и по приоритету, и по порядку работ.

## Приборы

```
node tools/qa-journeys-lint.mjs        # страж карты: поля, номера, сводка, покрытие маршрутов
```

Карта проверяется машиной с первого дня: она источник, из которого разметка `@covers` читает
идентификаторы, и опечатка в номере тихо превращается в путь, который нельзя покрыть.
