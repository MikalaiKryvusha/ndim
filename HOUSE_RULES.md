входом в механизм, а жест стражами намеренно не эмулируется — без двери инвалидация кэша не была

Двери читаются ТОЛЬКО на стенде (`isStand()` — localhost/127.0.0.1), в бою параметр игнорируется;
приём тот же, что у давно существующего `?db=` (выбор базы). Код — `src/lib/data/profile.ts`,
`currentSession()`. **Пишешь что-либо про гостя или вход — проверяй через эти двери, иначе проверка
идёт мимо продукта.**

**Эмулятор Firestore.** Требует Java (OpenJDK 21 установлена; в PATH попадает в **новом** сеансе
оболочки — если `java` не находится, добавь
`C:\Program Files\Microsoft\jdk-21.0.11.10-hotspot\bin` в `$env:PATH` на время команды).
Порт — **8181**, а не дефолтный 8080: на машине владельца 8080 занят `llama-swap`. Тесты порт не
знают — берут его из `FIRESTORE_EMULATOR_HOST`, который выставляет `firebase emulators:exec`.

**Эмулятор Storage (порт 9199)** — часть `npm run stand` с 2026-07-16 (bugs/14): у стенда есть
НАСТОЯЩИЕ фотографии (сид кладёт лица dev-пользователю и Анне; поведение фото и лайтбокс
проверяемы). Правила — `storage.rules` (черновик; в бой НЕ выпускать без bugs/04). ⚠️ При
загрузке файла эмулятор игнорирует Content-Type — сид чинит тип PATCH-ом метаданных, иначе
SVG в `<img>` не рендерится (DOM-проверки при этом зелёные — смотри пиксели: `naturalWidth`).
