🔑 **И класс, ради которого поправка написана так подробно.** Предсуд утверждает нечто о **ПАРЕ
(ветка, ствол)**, а ствол движется. Утверждение о паре, названное одним sha или вовсе без sha,
переживает собственную правду МОЛЧА — стража на отчёт нет. Отсюда форма, обязательная для
следующего предсуда (манифест → git-процесс п. 4): **два sha внутри самой формулировки и команда
перепроверки рядом с ней.** Проверка этого конкретного заявления стоит одной строки:

```bash
test "$(git merge-tree --write-tree <sha ствола> <sha ветки>)" = "$(git rev-parse <sha ветки>^{tree})" \
  && echo "тождественно" || echo "разошлось — числа автора НЕ равны числам слитого дерева"
```

## 3. Симуляция мержа в ствол

```bash
git merge-tree --write-tree main 721fa57 | grep -c '^CONFLICT'    # → 0
```

**КОНФЛИКТОВ НОЛЬ.** Карта окна предсказывала для этого шага два (`EXPERIENCE.md` и
`tools/meta-share.test.mjs`); **оба сняты АВТОРОМ до очереди** — второй правкой в своей ветке
(§5), первый мержем подтяжки `721fa57`. Прогноз карты этим не опровергнут, а исполнен: она
называла, ГДЕ разъедется, и разъехалось ровно там, просто резолв случился у автора, а не на
шаге мержа. Так и должно быть по манифесту (п. 3).

🔑 **И более сильный факт, чем «конфликтов ноль»:**

> 🔴 **ЭТОТ АБЗАЦ ПРОТУХ 2026-08-29 около 20:15 — см. поправку в шапке.** Он верен против
> `main` = `c84b2dc` и неверен против сегодняшнего ствола (`96bd29a`): деревья расходятся на
> 24 файла, `test:tools` даёт 566 у автора против 567 на слитом дереве. Текст оставлен
> дословно — он и есть улика класса «утверждение о ПАРЕ, названное одним sha». Проверка в одну
> строку приведена в поправке.

```bash
git merge --no-ff --no-commit 721fa57 && test "$(git write-tree)" = "$(git rev-parse 721fa57^{tree})"
# → дерево слияния ТОЖДЕСТВЕННО дереву ветки
```

Дерево, получающееся мержем, **побайтно совпадает с деревом ветки автора**. Отсюда следствие,
важное судье: её прогоны на голове `721fa57` и есть прогоны на слитом дереве — их не нужно
повторять после мержа, и расхождение между «зелено у автора» и «зелено в стволе» здесь
невозможно по построению.
