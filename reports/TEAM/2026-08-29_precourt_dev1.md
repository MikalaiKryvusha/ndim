
## 5. 🔴 ПЕРВЫЙ ЗАКАЗАННЫЙ ПЕРЕСЧЁТ: полное ли лечение стража

**Заказ Менеджера:** «*проверь, что лечение полное, а не адресное: руками написанных образцов в
страже больше остаться не должно*».

**Ответ: лечение АДРЕСНОЕ, а не полное. Рукописный образец остался — один, и вот он:**

```js
// tools/verify-catalog-hubs.mjs:264
const TOP_CLAIM = { ru: /топ по версии NDim Space/i, en: /top rated on NDim Space/i };
const TOP_LEDE  = { ru: CATALOG_COPY.ru.hubLede,     en: CATALOG_COPY.en.hubLede };   // :266 — вылечен
```

Образец СТРОКИ СМЫСЛА взят у продукта (это и есть лечение M1). Образец ЗАГОЛОВКА по-прежнему
написан руками.

🔬 **Но «остался» и «опасен» — разные утверждения, и второе я проверил МУТАЦИЕЙ, а не чтением.**
Сломал английскую половину `TOP_CLAIM` на заведомо несуществующую формулу:

```
✅ 🔴 страница без единой оценки НЕ обещает рейтинг в заголовке — страниц без оценённых 106, лгут 0   ← ЗЕЛЁНАЯ, и это ложь
✅ 🔴 та же правда в строке смысла — её видит человек — лгут 0
❌ страница С оценёнными по-прежнему называет себя топом (не обеднили) — страниц с оценёнными 72, замолчали 36
🔴 ИТОГ: 99 прошло, 1 провалов
```

**Что это значит поимённо:**
· рукописный образец ДЕЙСТВИТЕЛЬНО способен молча убить половину проверки — строка «лгут 0»
  осталась зелёной на сломанном образце, ровно класс M1;
· **но страж в целом краснеет**, потому что ТОТ ЖЕ константный образец используется на
  противоположной стороне (`mutedTitle`), где направление обратное: 36 из 72 «замолчали».

**Отсюда мой механический вывод и его граница.** Формально заказ не исполнен: рукописный
образец есть. Фактически риск ограничен и измерен: он не даёт МОЛЧАЛИВОГО зелёного у стража,
только у одной из двух его строк. **Достаточно ли этого — суждение, и оно за судьёй.** Дешёвое
усиление, если она решит его потребовать, названо: вывести `TOP_CLAIM` из продукта тем же
приёмом, что `TOP_LEDE`.

## 6. 🔴 ВТОРОЙ ЗАКАЗАННЫЙ ПЕРЕСЧЁТ: промах предсказания третьей мутации

**Заявленное объяснение автора:** ждал 14 сверенных страниц, получил 0, «потому что сверка

печатает: «сверено страниц **178**», то есть участвуют ВСЕ.

🔑 **И совпадение, которое судье стоит увидеть своими глазами:** «14», которое автор ожидал, —
это в точности **число ГРУПП**, а `compared` считает **СТРАНИЦЫ**. То есть его промах правдоподобнее

**Разбор — за судьёй.**
