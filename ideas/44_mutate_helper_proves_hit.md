# Идея 44 — `mutate()`: помощник мутационных проверок, доказывающий попадание

> **Создан:** 2026-08-22, Менеджером по предложению dev-2 (`EXP-0189`, «решение за Менеджером») ·
> **Родитель:** `EXP-0189` · «Журнал опыта»: порядок лечения — сначала убрать ловушку инструментом ·
> **Статус:** ❓ ожидает одобрения владельца; реализацию берёт dev-2 отдельной постановкой ·
> **Исходящее:** после боевой обкатки — кандидат в полевой отчёт KAIF (шаблон B, усиление слабых моделей)

## Боль, оплаченная полем

Три случая одного класса за двое суток (`EXP-0189`, родня `EXP-0180`, `EXP-0182`): агент ставит
мутацию строкой-заменой, замена **молча не попадает** (CRLF против `\n`, дрейф пробелов, устаревший
шаблон) — файл переписывается сам собой, прогон честно зелен на незамутированном коде, и агент
получает **ложный вывод о качестве проверки**: «тест не ловит мутацию» — приговор исправному тесту.
Рядом второй провал той же процедуры (`EXP-0190`): откат мутации `git checkout` по
незакоммиченному файлу дважды за смену стёр живую работу.

## Предложение

Один помощник `tools/lib/mutate.mjs`, три обязанности:

1. **Доказывает попадание ДО прогона:** после подстановки сравнивает содержимое; байт-в-байт
   совпало → ненулевой код и строка «🔴 МУТАЦИЯ НЕ ПОПАЛА — результат прогона ничего не значит».
2. **Отказывается мутировать грязный файл** (`git status` по пути): незакоммиченная правка →
   стоп с подсказкой «сначала коммит» (лечит `EXP-0190` по построению).
3. **Сам откатывает** содержимым, снятым в память до подстановки, — а не индексом git.

Форма вызова — из мутационного скрипта: `mutate(path, pattern, replacement)` → `restore()`.

## Критерии приёмки

- Мутация с непопавшим шаблоном падает кодом ≠ 0 ДО запуска проверяемого стража. [NOT-TESTED]
- Мутация по грязному файлу отказана с подсказкой. [NOT-TESTED]
- `restore()` возвращает байт-в-байт исходник (включая CRLF). [NOT-TESTED]
- Самотест помощника — на образцах с CRLF и с LF (обе дороги). [NOT-TESTED]
- Хотя бы один существующий мутационный прогон переведён на помощника как образец.

## Чего идея НЕ делает

Не переписывает существующие мутационные проверки скопом (они доказаны; переводим по мере касания)
и не отменяет правило «коммить до мутации» — помощник его МЕХАНИЗИРУЕТ, а не заменяет.
