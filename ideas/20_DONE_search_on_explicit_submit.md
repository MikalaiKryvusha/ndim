## Разбор

Сейчас (`bugs/50`) поиск на «Измерениях» стартует по мере ввода с паузой 250 мс — дебаунс
экономит дребезг, но каждый промежуточный запрос всё равно ходит в Firestore (догрузка
найденных карточек). Канон 1.x — поиск начинается ТОЛЬКО по явному действию человека.

Сделать:
1. Кнопка «Искать» у строки поиска (вид — по месту, это не развилка макетов: кнопка была
   в 1.x) + сабмит формы: Enter на десктопе и действие «поиск» Android-клавиатуры
   (`enterkeyhint="search"`, событие submit).
2. Посимвольный запуск поиска убрать; дебаунс становится не нужен.
3. Пустой ввод по-прежнему не ищет (тост 1.x «Введите текст для поиска» — снят в
   researches/12, `app.js:9230`).
4. Стражу `verify-bug50` обновить предмет: «ввод букв БЕЗ сабмита не порождает запросов
   Firestore» — это и есть новая экономия (класс EXP-0061: страж следит за поведением,
   не за литералами).
