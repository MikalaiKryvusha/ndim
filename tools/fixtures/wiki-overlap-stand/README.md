# Фикстура-свод под сид стенда — `tag-dims-approval`

Малый свод сверки с Википедией в том же формате, что боевой
(`test-results/wiki-overlap-{ru,en}.json`, снят `tools/measure-wikipedia-overlap.mjs`), но под
измерения стендового сида (`tools/seed-dev.mjs`). Нужен, чтобы прогон прибора
`tools/tag-dims-approval.mjs` был доказан на стенде, не касаясь боевой базы и не обходя Википедию.

```
node tools/tag-dims-approval.mjs --contour stand --svod-dir tools/fixtures/wiki-overlap-stand
```

**Что моделирует каждая запись** (класс известен человеку заранее — прибор обязан вывести его сам):

| Запись | Свод | Ждём |
|---|---|---|
| `cats` | русское описание — копия, ряд 28 слов | `needs-rewrite` |
| `travel` | английское описание — копия, ряд 50 слов | `needs-rewrite` |
| `star-wars-1977` | копия в русском + статья не найдена в английском | `needs-rewrite` — заимствование бьёт «не проверено» |
| `silence` · `math` | статья не найдена в одном из языков | `unchecked` |
| `taxi-driver-1976` | ряд 58 слов, но это ПЕРЕЧЕНЬ ИМЁН | `migrated` — длина ряда сама по себе не улика |
| `rocky-4-1985` | ряд 9 слов в обоих языках | `migrated` — граница порога (10) снизу |
| `alchemist-1988` · `theatre` · `running` · `spider-man-2002` · `yoga` | чисто | `migrated` |
| `early-rising` | 🔴 **записи в своде НЕТ** | класс НЕ присваивается — уходит отдельной строкой |

Последняя строка — главная: каталог вырос после того, как свод сняли (5111 → 5121), и такие
записи прибор обязан назвать по идентификатору, а не додумать им класс.

Разбор на стенде: `needs-rewrite` 3 · `unchecked` 2 · `migrated` 7 · **не в своде 37** = 49 записей
сида. Тридцать семь — это `early-rising` и тридцать шесть проб `probe-NN`, которые сид добавляет
отдельным циклом (`tools/seed-dev.mjs:217`). Их отсутствие в фикстуре намеренно: так стенд
моделирует боевую правду — каталог вырос уже после того, как свод сняли.
