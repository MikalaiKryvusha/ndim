# Фикстура-свод под сид стенда — `tag-dims-approval`

Малый свод сверки с Википедией в том же формате, что боевой
(`test-results/wiki-overlap-{ru,en}.json`, снят `tools/measure-wikipedia-overlap.mjs`), но под
измерения стендового сида (`tools/seed-dev.mjs`). Нужен, чтобы прогон прибора
`tools/tag-dims-approval.mjs` был доказан на стенде, не касаясь боевой базы и не обходя Википедию.

```
node tools/tag-dims-approval.mjs --contour stand --svod-dir tools/fixtures/wiki-overlap-stand
```

**Что моделирует каждая запись** (класс известен человеку заранее — прибор обязан вывести его сам):

| Запись | Свод | Ждём |
|---|---|---|
| `cats` | русское описание — копия, ряд 28 слов | `needs-rewrite` |
| `travel` | английское описание — копия, ряд 50 слов | `needs-rewrite` |
| `star-wars-1977` | копия в русском + статья не найдена в английском | `needs-rewrite` — заимствование бьёт «не проверено» |
| `silence` · `math` | статья не найдена в одном из языков | `unchecked` |
| `taxi-driver-1976` | ряд 58 слов, но это ПЕРЕЧЕНЬ ИМЁН | `migrated` — длина ряда сама по себе не улика |
| `rocky-4-1985` | ряд 9 слов в обоих языках | `migrated` — граница порога (10) снизу |
| `alchemist-1988` · `theatre` · `running` · `spider-man-2002` · `yoga` | чисто | `migrated` |
| `early-rising` | 🔴 **записи в своде НЕТ**, но на неё указывает ОДОБРЕННЫЙ кандидат | `owner-approved` — судит очередь кандидатов, а не свод |
| `probe-01` | записи в своде нет, кандидат есть, но в статусе `pending` | класс НЕ присваивается — одобрения не было |

Две последние строки — главные: каталог вырос после того, как свод сняли (5111 → 5121), судить
такие записи сводом нечем, и решает их судьбу ВТОРОЙ источник — очередь кандидатов
(`dim_candidates`, интервью №044 В4 = A). Одобренный кандидат даёт `owner-approved`; кандидат в
любом другом статусе и отсутствие кандидата вовсе — класса не дают, запись печатается поимённо.

🔑 Отсутствие кандидата — **не аномалия**: измерение заводится и ручной формой комнаты
(`admin/dims/+page.svelte` зовёт `createDim` напрямую, минуя очередь), и кандидата у такой записи
нет никогда. «Нет записи» — утверждение о ПОИСКЕ, а не о мире (`EXP-0165`).

Очередь кандидатов сидом не засевается — две записи (одобренную и ждущую) сеет сам страж
`tools/verify-tag-dims-approval.mjs`.

Разбор на стенде: `needs-rewrite` 3 · `unchecked` 2 · `migrated` 7 · `owner-approved` 1 ·
**без источника суждения 36** = 49 записей сида. Тридцать шесть — это пробы `probe-NN`, которые
сид добавляет отдельным циклом (`tools/seed-dev.mjs:216`).
