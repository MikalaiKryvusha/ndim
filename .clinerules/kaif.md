# Agent rules

This project is KAIF-wrapped. Before every task read `AGENT_GUIDE.md` (the canon) and `STATUS.md` (current state); think per `PHILOSOPHY.md`; debug per `BUG_FIXING_FRAMEWORK.md`; execute tasks per the fable loop (`/fable-method`, `/fable-judge`).

A message that opens with the word `resume` is an ORDER to run /resume in full before the rest of the message (KAIF 2.7).
